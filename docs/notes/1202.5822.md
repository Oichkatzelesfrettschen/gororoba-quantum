## Main claims and evidence

- [P] Hamiltonian dynamics is simulated by implementing linear combinations of unitary operations rather than products of unitaries.
- [P] The main tool nearly deterministically implements linear combinations of nearby unitaries and is optimal within a large class of methods; the resulting simulation scales better with the error than the product-formula methods of the time.
