The degree bounds concern the stated algebraic path representation. They are
neither a bound on the Taylor order sufficient to solve the repository's
equations nor a practical runtime estimate for the dimension-32 problem.
Arithmetic complexity over `D` differs from bit complexity and from an
implemented exact-real computation.

## Application to the Schur tangent question

Fix the real same-nullity locus `X` on the center's constant-norm sphere and
an admitted Schur pivot domain. The equations `Sbar(x)=0`, the sphere
equation, and `det A(x)!=0` describe a semialgebraic set. The nonvanishing
pivot condition remains part of the set after clearing denominators.

For a proposed direction `h`, form the auxiliary semialgebraic set

```text
E = {(t,v): 0<t<1, x0+t*v belongs to X}.
```

By the definition of the Bouligand tangent cone, `h` is a tangent direction
exactly when `(0,h)` belongs to `closure(E)`. Applying curve selection to
that proved closure membership gives a path `(tau(s),v(s))` in `E` with
`tau(s)>0`, `tau(s)->0`, and `v(s)->h`. Thus

```text
gamma(s)=x0+tau(s)*v(s) belongs to X,
(gamma(s)-x0)/tau(s) -> h.
```

This is an actual real path with the prescribed asymptotic direction.
The theorem does not establish the closure premise from a linearized or
quadratic necessary condition. A differentiable parametrization with a
specified nonzero velocity needs its own reparametrization argument; the
published path contract is continuity. An algorithmic use also needs an
exact representation of the starting point `(0,h)` and all coefficients.
Rational tests of selected directions do not prove a uniform statement for
every real direction in a candidate plane.

The useful next certificate is a closure-membership decision or an explicit
path for each proposed branch of the quadratic outer bound. A candidate
path must retain a real branch selector, the pivot inequation, norm and
rank identities, its starting point, and its leading direction. The existing
Coste curve-selection result supplies the qualitative bridge; Basu-Roy adds
representation and algorithmic bounds. Neither source completes the
repository's higher-order lifting, tangent-cone equality, attachments, or
Rocq formalization.
