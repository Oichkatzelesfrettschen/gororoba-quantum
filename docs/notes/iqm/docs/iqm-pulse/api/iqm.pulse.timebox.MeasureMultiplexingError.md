# iqm.pulse.timebox.MeasureMultiplexingError

*exception* iqm.pulse.timebox.MeasureMultiplexingError  
Error in multiplexing two `MeasureBoxes` instances together.

Raised for example when the `MeasureBoxes` instances have overlapping `MeasureBoxes.measure_components`.
