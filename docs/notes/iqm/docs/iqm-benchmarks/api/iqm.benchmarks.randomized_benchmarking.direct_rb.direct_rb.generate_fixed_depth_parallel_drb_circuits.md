Generates DRB circuits in parallel on multiple qubit layouts.

> The circuits follow a layered pattern with barriers, taylored to measure EPLG (arXiv:2311.05933), with layers of random Cliffords interleaved among sampled layers of 2Q gates and sequence inversion.

- **depth** ([*int*](https://docs.python.org/3.11/library/functions.html#int "(in Python v3.11)")) – The depth (number of canonical DRB layers) of the circuits.

- **num_circuit_samples** ([*int*](https://docs.python.org/3.11/library/functions.html#int "(in Python v3.11)")) – The number of DRB circuits to generate.
