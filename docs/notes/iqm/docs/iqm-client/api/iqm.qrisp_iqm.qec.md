# qec

Full path: iqm.qrisp_iqm.qec

Quantum Error Correction utilities.

Provides the `DetectorExperiment` decorator for defining parameterised QEC experiments, computing logical error rates (LERs) via Stim + PyMatching, and extracting circuits for hardware execution.
