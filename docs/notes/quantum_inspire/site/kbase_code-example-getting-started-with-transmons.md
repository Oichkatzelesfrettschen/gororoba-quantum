# Code example: Getting started with the transmon backends

We have created some basic examples to get you started with using the transmon backends of the Quantum Inspire 2.0 cloud. We have separate notebooks for backends in the Tuna and Starmon families. The notebooks cover the following topics:

1.  Introduction
2.  Connecting to the **QI Backend**
3.  Running your first quantum circuit

- 3.1. Creating a Bell pair state without using Qiskit transpiler
- 3.2. Creating a Bell pair state using Qiskit transpiler
- 3.3. Creating a Bell pair state using Qiskit transpiler (Advanced)

4.  Performing a qubit T1 measurement using mid-circuit measurements
5.  Performing a Rabi oscillation experiment using mid-circuit measurements

These notebooks are hosted on [DiCarlo lab's GitHub page](https://github.com/DiCarloLab-Delft/). The Tuna notebook can be accessed [here](https://github.com/DiCarloLab-Delft/QuantumInspireUtilities/blob/main/qi_utilities/notebook_guides/0.1_getting_started_tuna_devices.ipynb). The Starmon notebook can be accessed [here](https://github.com/DiCarloLab-Delft/QuantumInspireUtilities/blob/main/qi_utilities/notebook_guides/0.0_getting_started_starmon7.ipynb).
