## Main claims

[P] For v = v1 + v2 e8 in the sedenions, with v1 = x1 e0 + u, v2 = x2 e0 + w, and u, w imaginary octonions, det L_v = D1(v)^4 D2(v)^2, where D1 = ||v||^2 and D2 = D1^2 - 4(||u||^2 ||w||^2 - <u,w>^2); the quartic D2 alone detects the nonzero left zero divisors.

- [P] Setup (Sec. 2.1): S = O + O with (a + b e8)(c + d e8) = (ac - d* b) + (da + b c*) e8, e8^2 = -1, e8 x = x* e8 (so e8 anticommutes with imaginary octonions), and Delta(v) = det M(v), where M(v) is the 16 x 16 matrix of L_v. Delta(v) = 0 iff v is a left zero divisor (Sec. 2.2).
- [P] Definition 3.1 and Lemma 3.2: D1(v) = ||v1||^2 + ||v2||^2 = ||v||^2. Lemma 3.3: for v != 0, D2(v) = 0 iff x1 = x2 = 0, ||u|| = ||w||, <u,w> = 0. The proof writes A = ||u||^2, B = ||w||^2, gamma = <u,w>, D2 = (x1^2 + x2^2 + A + B)^2 - 4(AB - gamma^2), and bounds D2 >= (A - B)^2 + 4 gamma^2 >= 0.
- [P] Lemma 3.4: M(v) = [[L_{v1}, -R_{v2} tau], [L_{v2} tau, R_{v1}]] with tau octonion conjugation. Lemma 3.5: det L_x = det R_x = ||x||^8 on O. Lemma 3.6: for imaginary u, w there is g in G_2 with g u = r e1 and g w = p e1 + q e2.
- [P] Theorem 3.7: Delta(v) = D1(v)^4 D2(v)^2, and v != 0 is a left zero divisor iff D2(v) = 0. The proof conjugates M(v) by T_g = g + g to reach the quaternionic normal form, permutes M to a block-diagonal F_{a,b} + G_{a,b}, identifies F_{a,b} with L_{a + b e4} on O (determinant D1^4 by Lemma 3.5), and computes det G_{a,b} = (det_C G(alpha, beta, q))^2 for a complex 4 x 4 matrix by a Schur complement in Appendix A, det_C G = (|alpha|^2 + |beta|^2 + q^2)^2 - 4 (Im alpha)^2 q^2.
- [P] Corollary 3.8: v != 0 is a left zero divisor iff x1 = x2 = 0, ||u|| = ||w||, <u,w> = 0, attributed to Moreno (reference [3]).
- [P] Theorem 3.9: D1 = sum_m a_m^2 and D2 = (sum_m a_m^2)^2 - 4(sum_{i=1..7} a_i^2 sum_{i=9..15} a_i^2 - (sum_{i=1..7} a_i a_{i+8})^2) in components a_0..a_15.
- [P] Section 4: E = {(u,w) in Im(O)^2 : ||u|| = ||w|| = 1, <u,w> = 0} = V_2(R^7), an S^5-bundle over S^6. Theorem 4.2: the set Z of nonzero left zero divisors is diffeomorphic to (0,infinity) x V_2(R^7) through Phi(r,(u,w)) = r(u + w e8), of dimension 12. The introduction states that the algebraic zero-divisor locus in R^16 is singular and the normalized nonzero locus is smooth.
- [P] Section 5: on the slice v1 = (0,X,Y,Z,0,0,0,0), v2 = (0,Y,Z,X,0,0,0,0), D2 = 4(XY + YZ + ZX)^2 and the zero set is the quadratic cone XY + YZ + ZX = 0; the form has signature (1,2), an A_1 singularity at the origin (Remark 5.4).
- [P] The paper reports no computer verification; the argument is symbolic. Related-work citations include Albuquerque and Majid as reference [11], J. Algebra 220 (1999), 188-224, and Reggiani (note 2411.18881).

## Mapping to this repository

Convention map.

- [I] The paper's doubling (a + b e8)(c + d e8) = (ac - d* b) + (da + b c*) e8 is the doubling in the gororoba_quantum/cd_core.py module docstring, (ac - conj(d) b, d a + b conj(c)). In cd_core.cd_sign(16, i, 8) = +1 with index i xor 8, so e_{8+i} = e_i e_8, which is the pairing a_i with a_{i+8} in Theorem 3.9; cd_sign(16, 8, i) = -1 for i >= 1, which is the anticommutation of e8 with imaginary octonions. The match rests on the displayed formula and the index pairing. The determinant carries no orientation evidence: the rephasing e_p -> -e_p turns L_v into the right-multiplication matrix of the opposite algebra, and det R_v = det L_v on all vectors tested (below).
