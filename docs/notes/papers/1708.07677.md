## Main claims and evidence

- [P] QuMA rests on three elements: a codeword-based event control scheme, queue-based precise event timing control and a multilevel instruction decoding mechanism (abstract).
- [P] Time points on the experiment timeline carry timing labels; events attach to a label and fire when the timer reaches it, with a 5 ns cycle time throughout the paper.
- [P] Typical pulse parameters in the paper: 20 ns single-qubit Gaussian pulses, 40 ns calibrated gates, 300 ns-2 us pulsed measurement.
- [P] The prototype was validated on a single transmon with a standard gate-characterization experiment (abstract).

## Limits

- [P/I] A single-qubit prototype from 2017; later control hardware is not described.
- [P/I] The paper does not describe the cloud job layer, shot repetition scheduling or any per-shot software overhead.
- [P/I] A hardware-timed sequencer fixes the intra-shot timing; the interval between shots is set by the experiment loop, which this paper does not characterize for Quantum Inspire.
