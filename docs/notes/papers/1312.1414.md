## Main claims and evidence

- [P] A d-sparse Hamiltonian is simulated with query complexity sublogarithmic in the inverse error; the analysis uses a new form of "oblivious amplitude amplification" that works without a reflection about the input state.
- [P] Lemma 3.6 (oblivious amplitude amplification): for unitaries U and V and theta in (0, pi/2), if U|0>|psi> = sin(theta)|0>V|psi> + cos(theta)|Phi_perp> for every input psi, with Pi|Phi_perp> = 0 for Pi = |0><0| (x) 1, then repeated reflections amplify the encoded V obliviously.

## Mapping to this repository

- [I] Lemma 3.6 needs the encoded operator to be proportional to a unitary, and `L_a / 2` for a two-term zero divisor is singular. Its singular values are constant on each of the three sectors in [singular_sector_dynamics.md](../singular_sector_dynamics.md): 0 on dark, `1/sqrt2` on S-, 1 on bright. The lemma therefore applies sector by sector, where `L_a / 2` restricts to a multiple of an isometry. The general per-singular-value form is the quantum singular value transformation of [1806.01838](1806.01838.md).
- [I] The reflection about the ancilla zero space is a Z on the single LCU ancilla, a virtual frame change on IBM processors, so each amplification round costs two block-encoding calls.
