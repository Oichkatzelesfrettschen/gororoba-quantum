## Statements

- [P] Abstract (p. 1): a complex square matrix whose elementwise absolute value has total support maps to a phased doubly stochastic matrix by diagonal scaling; a bottleneck variant of Birkhoff's algorithm needs O(N log(N/epsilon)) permutations (epsilon the l1 reconstruction error), and a largest-weight greedy variant needs about 2N terms on dense matrices (observed average about 2.4N), against O(N^2) permutation or Pauli terms in the standard decompositions.
- [P] Section 2 (p. 3): LCU embeds A = sum_k beta_k U_k with normalization alpha = sum_k |beta_k| and success probability ||A psi||^2 / alpha^2 on the all-zero ancilla outcome; the ancilla register takes ceil(log2 K) qubits for K terms.
- [P] Theorem 1 (Phased Birkhoff-von Neumann Decomposition, p. 3): if |A| has total support there exist positive diagonal D_1, D_2 with D_1 A D_2 = sum_k w_k P_k, w_k >= 0, sum w_k = 1, each P_k a unitary phased permutation matrix (one entry e^(i theta_ij) per row and column). The proof combines Sinkhorn's theorem with the classical Birkhoff-von Neumann theorem.
- [P] The convex combination has alpha = 1 exactly for the scaled matrix S (abstract), so the uniform superposition over terms is an eigenvector of S with eigenvalue 1.
- The theorem number of the O(N log(N/epsilon)) bound is not on pages 1-3: verify.

## Mapping to this repository

- [I] Left multiplication by a basis unit of A_5 is a signed permutation (cd_core; note on arXiv 1811.08580), so a generic L_a = sum_k a_k L_{e_k} is already a 32-term linear combination of signed permutations: ceil(log2 32) = 5 ancilla qubits and alpha = sum_k |a_k|, against the 497 Pauli terms and 9 ancillas recorded in `docs/evidence/hhl-qsvt-falsify/README.md`. The kernel-map circuit uses two terms and one selector qubit. This paper's Birkhoff route targets generic dense matrices and adds nothing for an operator that is natively a signed-permutation sum; it matters only if a later case needs a dense non-algebra matrix.
- [I] The paper's phased permutations cover signs as phases e^(i pi); the Sinkhorn scaling step changes the matrix by D_1, D_2, so the encoded operator is D_1 A D_2 and a kernel statement transfers only after undoing the scaling (nullity is preserved by invertible diagonal scalings).
- [I] No hardware or fault-tolerance claim bears on Heron r2 here; the results are circuit-width counts.
