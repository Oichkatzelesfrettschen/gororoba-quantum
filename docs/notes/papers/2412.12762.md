## Statements

- [P] Abstract (p. 1): for a matrix that is a linear combination of permutations, positive coefficients make the eigenvalues resilient to bit-flip errors; mixed-sign coefficients and phase flips show less resilience, with small eigenspectrum perturbation at small error rates (numerical evidence); the block-encoding case with a control register is discussed.
- [P] Section 1.1 (p. 2): any square matrix is D_1 (sum_i alpha_i Pi_i) D_2 for diagonal D_1, D_2 (Sinkhorn) and permutations Pi_i, so the framework covers arbitrary matrices; the paper's own 2 x 2 example is A = D_1 (alpha_1 Pi_1 + alpha_2 Pi_2) D_2.
- [P] Section 1.2 (p. 2): the probabilistic bit-flip and phase-flip model bounds eigenvalue perturbation (Gershgorin-based) and relates it to input-state fidelity.

## Mapping to this repository

- [I] The kernel-map circuit is a mixed-sign two-permutation sum, the case the paper reports as least resilient to bit and phase flips; the paper's claim is numerical, so it motivates the circuit's null arms (cocycle-free SELECT, flipped-sign SELECT, selector-disconnected skeleton) and does not predict the measured contrast.
- [I] The error model is Pauli bit and phase flips on permutation terms, not Heron r2 gate noise; no quantitative bound transfers.
