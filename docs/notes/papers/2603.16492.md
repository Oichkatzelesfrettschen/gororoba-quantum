## Statements

- [P] Abstract (p. 1): C-NOT count of general n-qubit state preparation improved from (23/24) 2^n to (11/12) 2^n; a single-ancilla block-encoding protocol for a 2^(n-1) x 2^(n-1) matrix uses the spectral norm as subnormalization (alpha = ||A||_2) with C-NOT leading term (11/48) 4^n; for a rank-K matrix the leading term is (2^(ceil(log2 K)) + 11/12) 2^n.
- [P] Section I.B (p. 2): the method builds on the Block-ZXZ decomposition of Krol et al. (2024); the paper names optimal normalization together with rank-adjustable C-NOT count as new, and states that existing protocols (FABLE, BITBLE) have not reached alpha = ||A||_2.
- [P] Page 1 and Fig. 1: the lower bound for arbitrary n-qubit state preparation is (1/2) 2^n C-NOT gates; the paper frames C-NOT count as the primary cost metric, citing two-qubit gate error as dominating the physical error budget.

## Mapping to this repository

- [I] This is the comparison point for the claim in `docs/evidence/hhl-qsvt-falsify/README.md` that a dense 32 x 32 operator needs a large generic block-encoding. The leading term (11/48) 4^n encodes a 2^(n-1) x 2^(n-1) matrix, so a 32 x 32 matrix is n = 6 and the leading term is about 939 C-NOT gates (arithmetic on the abstract's formula; the paper's tables not read: verify). The kernel-map circuit's two-term signed-permutation SELECT is far smaller by construction, but no transpiled count exists for either: not measured. The structured encoding is the right comparison for the A_5 operators and the generic encoding the right comparison for the dense real SPD case in the falsification record.
- [I] alpha = ||A||_2 would remove the 7.8 to 8.8 factor that the 497-term Pauli LCU adds to the effective condition number in the falsification record, but the infinite condition number on the zero-divisor locus remains.
