## Statements read

- [P] Introduction (p. 1): the sh Lie algebra of closed string field theory is defined on the full Fock complex with the BRST differential `Q`; the genus zero `n`-fold string product is `[B_1, ..., B_n]`, and the basic equation (1) relates these brackets to `Q` through a sum over unshuffles with appropriate signs.
- [P] Definition of a graded Lie algebra (p. 6): a graded vector space `V = {V_p}` with a graded skew commutative bracket `V tensor V -> V` taking `V_p tensor V_q` to `V_(p+q)` and satisfying the graded Jacobi identity `[u, [v, w]] = [[u, v], w] + (-1)^(pq) [v, [u, w]]`.
- [P] Definition of an sh Lie structure (p. 6): on a differential graded vector space `V` with differential `l_1 : V_i -> V_(i-1)`, "a collection of skew symmetric linear maps `l_n : V^(tensor n) -> V` of degree `2 - n` (for cochain complexes, and `n - 2` for chain complexes)" satisfying the quadratic relation (2), a sum over `i + j = n + 1` and unshuffles `sigma` of `e(sigma) (-1)^sigma alpha(i, j) l_i(l_j(v_sigma(1) ... v_sigma(j)) v_sigma(j+1) ... v_sigma(n)) = 0` with `alpha(i, j) = -1` only if `i` is odd and `j` is even. The text notes that `l_2` is a usual graded Lie bracket and that when `l_3 = 0` the definition gives the graded Jacobi identity; `l_3` is in general a homotopy between the Jacobi expression and 0.

## Mapping to this repository
