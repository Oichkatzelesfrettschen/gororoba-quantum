## Statements

- [P] Theorem 4.5 (p. 9): for a Boolean system `F` with solutions of minimum Hamming weight `h` and Macaulay degree `d`, the condition number of the Macaulay linear system is bounded below in terms of `h`.
- [P] Theorem 4.7 (p. 10): for `d >= n` the truncated QLS condition number kappa_b(M) = ||M|| ||M^+ b|| / ||b|| is bounded below by the smallest l2-norm solution.
- [P] Section 4 (p. 11): Grover search needs O(h^(1/4) sqrt(binom(n, h))) polynomial evaluations, so for d + h >= n Grover performs at least as well as the HHL-based algorithm, and the Chen-Gao algorithm with d = 3n is definitely outperformed.
- [P] Section 3 (p. 7): classically the solving degree is at most n + 2 (Caminata and Gorla), so a Groebner basis follows from Gaussian elimination of the Macaulay system.
