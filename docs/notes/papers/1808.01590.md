## Algorithm

[P] Fig. 1 and section I: four stages with nested loops that tighten a
Euclidean tolerance epsilon whenever a step fails: primitive cell search
(steps a-e), space group operation search (f-g), identification of the
space-group type (h-k) and finalization (l-o).

| Step | [P] Content |
| --- | --- |
| (a) | pure translations (I, w): candidates are differences of sites of the least frequent atom type, accepted when every atom maps onto a same-type atom; brute force O(N^3), reduced in practice to O(N^2 log N) by sorting |
| (b)-(d) | choose a right-handed primitive basis with \|T_p\| = round(V_i / V_p) (Eq. 6); on failure tighten epsilon, thin out translations, or restart (a) |
| (e) | Delaunay-reduce the primitive basis (Eq. 7, det Q_D = 1), map coordinates, average translation-equivalent atoms |
| (f) | lattice point group: every integer matrix with entries -1, 0, 1 and \|det\| = 1 is tested by comparing the metric G with W^T G W, lengths by epsilon and angles by Eq. (10) |
| (g) | space group operations (W, w): translation candidates x~ - W x over same-type pairs, accepted by condition (5) on all atoms |
| (h) | crystallographic point group from the traces and determinants of the rotations (Appendix B tables); failure restarts (a) |
| (i)-(k) | transform to a conventional cell by Laue class and match against the operations decoded from Hall symbols, after Grosse-Kunstleve and Adams, fixing the origin shift |
| (m) | remove residual distortion from the conventional basis by averaging symmetry-equivalent lengths, a Cartesian rotation R to the idealized cell (as, bs, cs) |
| (n), (o) | rebuild the input cell's operations from the Hall dataset; Wyckoff positions; a distortion-free conventional structure |

[P] Equivalence of two points (section II, Eq. 5): |(a, b, c)(Delta x -
round(Delta x))| < epsilon, a Cartesian distance in the units of the basis.
Machine precision (section III): reduction modulo Z uses epsilon' = 1e-10,
mapping coordinates into [-epsilon', 1 - epsilon'). Angles (section V-A): if
no angle tolerance is given, the distance tolerance is converted through Eq.
(10), sin|Delta theta| sqrt((|a~| + |a|)(|b~| + |b|)/4) < epsilon.

[P] Section I names other symmetry finders: FINDSYM (ISOTROPY, source not
public), cctbx/sgtbx, sginfo and AFLOW-SYM (GPL).

## Repository use

[I] spglib's input is a periodic three-dimensional cell; its rotations are
3 x 3 integer matrices in the cell basis, and the library raises
`SpglibError: lattice has to be a (3, 3) array` on any other shape
(replay section 5). A finite set enters only through a periodic embedding,
here a cubic box of edge 20 around point sets of radius at most sqrt(5). The
box's m-3m holds the full symmetry of each set checked, so the
zero-translation operations are the set's own point group.

[I] seekpath passes `symprec` as epsilon and `angle_tolerance` through; the
integer point sets of the replay are exact, so any epsilon below half the
nearest-neighbor distance returns the same group.
