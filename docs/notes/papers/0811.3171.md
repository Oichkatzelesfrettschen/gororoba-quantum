## Statements

- [P] Abstract (p. 1): for a sparse N x N matrix A with condition number kappa, the algorithm estimates x^dagger M x for the solution of A x = b in poly(log N, kappa) time, where classical algorithms need O(N sqrt(kappa)) time for the same task.
- [P] Introduction (p. 1): the algorithm prepares |b>, applies e^(iAt) in superposition by Hamiltonian simulation, extracts eigenvalues lambda_j by phase estimation, and applies a controlled rotation taking |lambda_j> to C lambda_j^(-1)|lambda_j>, which succeeds with a probability that depends on kappa; the runtime scales as kappa^2 log(N) / epsilon with the singular values of A in [1/kappa, 1].
- [P] Introduction: the output is a state |x> proportional to A^(-1)|b>, useful for expectation values and not for reading out all N components.
