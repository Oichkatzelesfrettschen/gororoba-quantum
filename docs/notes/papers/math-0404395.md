## Statements and hypotheses

- [P] Setting (p. 1): `A_n = R^(2^n)` with `x y = (x1 y1 - conj(y2) x2, y2 x1 + x2 conj(y1))` and `conj(x) = (x1, -x2)`; for
  `n >= 4` the algebra is flexible but neither normed nor alternative. An element `a` is alternative when
  `(a, a, x) = 0` for all `x`; the canonical basis consists of alternative elements (p. 9, citing Schafer).
- [P] Pure and doubly pure elements (pp. 3-4): `a = (a1, a2)` is doubly pure when `a1` and `a2` are pure; with
  `ee0 = e_(2^(n-1))` and `a~ = a ee0 = (-a2, a1)`, doubly pure means orthogonal to `e0` and `ee0`. Lemma 1.1 (p. 4):
  for any `a` and doubly pure `x`, `a~ x = -(a x)~`. Corollary 1.3 (p. 5): for nonzero doubly pure
  `a` and `n >= 3`, `H_a = span{e0, a~, a, ee0}` is a copy of the quaternions.
- [P] Proposition 1.4 and Corollary 1.5 (pp. 5-6): for doubly pure `a, b`, `(a b)~ = a (b~)` exactly when `a` is orthogonal
  to `b` and `a~` is orthogonal to `b`; `(a, ee0, b) = 0` for `b` in `H_a` and `(a, ee0, b) = 2 a~ b` for `b` in `H_a^perp`.
- [P] Theorem 2.2 (p. 7) and Theorem 2.3 (p. 9), the Yui conjecture: for `n >= 4` and nonzero `a, b` with `(a, x, b) = 0` for
  all `x`, the pure parts of `a` and `b` are linearly dependent. Lemma 2.1 (p. 7) is the supporting statement: if `a` is
  doubly pure and `a x = 0` for all `x` in `H_a^perp`, then `a = 0`; the proof uses only that `e_(2^(n-2))` is an
  alternative element of norm one.
- [P] Proposition 3.1 (pp. 9-10): a pure element `a = r c + s ee0` with `r != 0` and `c` doubly pure is alternative exactly
  when `c` is. Lemma 3.2 (p. 10): for pure `a, b`, `L_(a,b)^2 (x, y) = (A x - S y, A y + S x)` with `A = L_a^2 + R_b^2` and
  `S = (a, -, b) = R_b L_a - L_a R_b`. Theorem 3.3 (p. 11): for pure `a, b`, `(a, b)` is alternative in `A_(n+1)` exactly when
  `a` and `b` are alternative and linearly dependent. Hence the alternative elements of `A_(n+1)` form a cone over those
  of `A_n` (p. 12): `Alt_4 = {(r a, s a) : a in A_3}`.
- [P] Section 4 (pp. 12-15): `a` is strongly alternative when `(a, a, x) = (a, x, x) = 0` for all `x`. The example on p. 12
  shows `e1` alternative but not strongly alternative in `A_4`: `(e4 + e15, e4 + e15, e1) = 2 e10`. Lemma 4.1 (p. 13):
  `(x, a, y) = 0` for all `x, y` forces `a` real. Theorem 4.2 (p. 13): a pure strongly alternative element of `A_(n+1)` is a
  multiple of `ee0`. Corollary 4.3 (p. 14): an automorphism of `A_n`, `n >= 4`, sends `ee0` to `+-ee0`; the remark that
  follows rederives the Eakin-Sathaye structure `Aut(A_(n+1)) = Aut(A_n) x S_3` for `n >= 3`, with the order-6 group
  generated by `tau(x, y) = (x, -y)` and the order-3 map `mu`.
- [P] Section 5 (pp. 15-18): `a` alternates with `b` when `(a, a, b) = 0`, strongly when also `(a, b, b) = 0`; strong
  alternation implies alternation implies `||ab|| = ||a|| ||b||` (pure `a`), and neither converse holds (p. 16 example:
  `a = e1 + e10`, `b = e15` give `||ab|| = ||a|| ||b||` but `(a, a, b) = 2 e4`). Theorem 5.1 (p. 17): for doubly pure `a`,
  `b` in `H_a^perp` with `a` alternating strongly with `b`, `span{e0, a, b, ab}` is a quaternion subalgebra and
  `span{e0, a, b, ab, a~b, -b~, a~, ee0}` an octonion subalgebra. Theorem 5.2 (p. 18): `a` alternates with `b` exactly when
  `{a, b}` and `{a, ab}` are normed subsets, and alternates strongly exactly when `{a, b, ab}` is normed.

## Convention map and cd_core check

[I] Product. With the conjugation bars restored, the printed doubling is `cd_core`'s
`(a,b)(c,d) = (ac - conj(d) b, d a + b conj(c))`, and the basis index is the XOR index (`e_(2^(n-1) + i) = (0, e_i)`).
The printed products of the examples on pp. 12 and 16 reproduce exactly under `cd_core.cd_sign(16, p, q)`:
`e1 e15 = -e14`, `e10 e15 = +e5`, `e1 e5 = -e4`, `e10 e14 = +e4`, `e4 e14 = -e10`, `e15 e5 = +e10`.

[I] Check results: no mismatch. A scratch script (ignored `docs/local/`, run with `-I`) tested the theorems with
exact rational arithmetic:

| Paper statement | Result under `cd_core` |
| --- | --- |
| `(e4 + e15, e4 + e15, e1) = 2 e10` (p. 12) | reproduced exactly; `(e1, x, x) = -2 e10` |
| `(a, a, b) = 2 e4` and `\|ab\|^2 = \|a\|^2 \|b\|^2 = 2` for `a = e1 + e10`, `b = e15` (p. 16) | reproduced exactly |
| `Alt_4 = {(r a, s a)}` (Theorem 3.3) | 0 failures on 60 random `(x, y)`; random independent pure halves gave nonzero `(x, x, y)` in 20 of 20 trials |
| cone structure at dimension 32 | 0 failures on 10 random elements `(r a, s a)`, `a = (r1 c, s1 c)` |
| two-term alternative elements `e_i + s e_j` | 126 at `D = 16` and 342 at `D = 32`, equal as sets to the recursion of Proposition 3.1 and Theorem 3.3 |
| strong alternativity | among the basis elements of `A_4`, only `e8 = ee0` passed the random test (Theorem 4.2) |
| Theorem 5.1 remark: `b = s c - r ee0` for `a = r c + s ee0` | `(a, a, b) = (a, b, b) = 0`, `\|a\| = \|b\|`, `a . b = 0` for `c = e3` and for `c = e1 + e10` |

[I] The two-term alternative elements coincide with the two-term elements of annihilator dimension zero: the 126
(dimension 16) and 342 (dimension 32) elements `e_i + s e_j` with `(x, x, y) = 0` for all basis `y` are exactly the
two-term elements whose left multiplication has full rank, and the 342 equals the nullity-0 row of the
[sparse census](../topics/cayley_dickson_sparse_census.md). The paper proves one direction in general (alternative
elements are normed, so they are not zero divisors); equality of the two sets on the two-term domain is a finite
observation of this note, not a theorem of the paper.

## Repository bearing

[I] Claims in `docs/state/research_state.json`. `sedenion-g2-bundle` (the zero-product pair space `G2` of the sedenions)
and `a5-stiefel-universal` (every nonzero `A_5` Stiefel element is a zero divisor): none directly; Theorem 3.3 and Lemma 3.2
are the squared-multiplication formula that [math-0512517](../math-0512517.md) Theorem 2.3 states for
`L_(a,b)^2`, and the elements of Theorem 5.1 supply octonion subalgebras inside `A_n` that
[math-0512516](math-0512516.md) uses to describe monomorphisms. `algebra-device-operational-falsifiers` (real-left
normality at dimensions 2 to 64): none. The Eakin-Sathaye structure in Corollary 4.3 matches the exact result of the
[sedenion automorphism evidence](../../evidence/sedenion-automorphisms/README.md) at `n = 4`; the paper does not compute
`Aut(A_5)` or beyond.

[I] Moreno's Stiefel question (`math/0512517` Section 5): none; this paper predates it and treats alternativity, not
the Stiefel set. Dimensions 32 and above: Theorem 3.3 and Theorem 4.2 hold for every `n`, so they give the alternative
elements of dimensions 32, 64 and beyond as a cone over those of the previous level; no counts are given.
