## Main claims and evidence

- [P] A 2.84 tonne-year xenon exposure with a nuclear-recoil window up to about 270 keV observes one event consistent with a 248 +- 23 (stat) +- 23 (sys) keV nuclear recoil where the background expectation is low.
- [P] The profile likelihood ratio gives 2.6 sigma global significance after the look-elsewhere correction, 3.4 sigma maximum local.

## Mapping to this repository

- [I] A single event at 2.6 sigma global is in tension with the background-only model, not a detection; the repository's multiplicity-controlled nondetection wording (results/live/PATCH_WINDOW_FINDINGS.md) applies the same discipline in the other direction.
