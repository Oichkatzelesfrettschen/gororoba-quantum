## Setting and conventions

- [P] Introduction (p. 1): for a local ring `(R, m)` and an ideal `I`, the fiber cone is `F(I) = sum_(n>=0) I^n / m I^n`; its Krull dimension is the analytic spread `a(I)`, `ht I <= a(I) <= min(mu(I), dim R)`, and a minimal reduction of `I` is generated by `a(I)` elements when `R/m` is infinite.
- [P] Section 2 (p. 2): `e(F(I))` is the multiplicity of `F(I)`; if `F(I)` is Cohen-Macaulay then `e(F(I)) >= mu(I) - a + 1`, with equality called minimal multiplicity; the reduction number with respect to a minimal reduction `J` is `r_J(I) = min{n >= 0 : J I^n = I^(n+1)}`.

## Theorem statements

- [P] Theorem 1.1 (Shah, p. 1): if `F(I)` is Cohen-Macaulay and `J` is a minimal reduction, then `mu(I^n) = sum_(i>=0) [mu(I^i) - length(J I^(i-1) / (J I^(i-1) cap m I^i))] C(n + a - i - 1, a - 1)` for all `n >= 0`. The introduction states that Shah conjectured the converse and that the paper proves it.
- [P] Theorem 2.1 (p. 2): for a local ring `(R, m)`, any ideal `I` and any minimal reduction `J`, the following are equivalent: (1) `F(I)` is Cohen-Macaulay; (2) `H(F(I), t) = (1/(1 - t)^a) sum_(i=0)^r length(I^i / (J I^(i-1) + m I^i)) t^i` with `r = r_J(I)` and `a = dim F(I)`; (3) `e(F(I)) = sum_(n=0)^r length(I^n / (J I^(n-1) + m I^n))`. The proof of (1) implies (2) uses that `J F(I)` is generated by a homogeneous system of parameters, hence a regular sequence, so the numerator is the Hilbert series of `F(I)/J F(I)`.
- [P] Remark 2.2 (p. 3): if `F(I)` is Cohen-Macaulay, `r_J(I)` equals the degree of the numerator of the Hilbert series of `F(I)` in reduced form, so it does not depend on the minimal reduction `J`.
- [P] Corollary 2.3 (Shah, p. 3): if `I` has analytic spread `a` with a minimal reduction `J = (x_1, ..., x_a)` satisfying `J I = I^2` and `x_1, ..., x_a` is a regular sequence, then `F(I)` is Cohen-Macaulay with minimal multiplicity.
- [P] Introduction (p. 1) on Section 3: the paper defines ideals of minimal mixed multiplicity in Cohen-Macaulay local rings, computes the Hilbert series of their fiber cone, and shows that for such ideals the fiber cone is Cohen-Macaulay if and only if `r(I) <= 1`.

## Mapping to this repository

- [I] Theorem 2.1 holds for any ideal of a local ring and needs no hypothesis the repository ideals fail, apart from an infinite residue field; the repository works over `F_p`, and base change to `R[X]` localized at `m R[X]` supplies the infinite field without changing the Hilbert function of `F(I)`. The criterion therefore decides Cohen-Macaulayness of the A_5 fiber cone `F(I)` from its Hilbert series and the Hilbert series of `F/J F` ([A_5 exceptional fiber findings](../topics/a5-exceptional-fiber-findings.md)).
- [I] Necessary half, computed from the tracked Hilbert functions by the numerator `N(t) = (1 - t)^a sum_d h_d t^d` (exact integer arithmetic; the coefficients of `N` must be nonnegative integers): for the pair X, with `h = 1, 15, 51, 122, 240` and `a = 4`, `N = 1, 11, -3, 4, -1`, so `F(I)` is not Cohen-Macaulay if its dimension is 4. For the pair E8-bar to N, with `h = 1, 21, 83` and `a = 5`, `N = 1, 16, -12`, so it is not Cohen-Macaulay if its dimension is 5. These two verdicts use only certified degrees of `F` itself.
- [I] Consistent with the criterion and not proven by it: for E8-bar to VB, `h = 1, 10, 34, 80, 155` and `a = 4` give `N = 1, 6, 0, 0, 0`, the numerator `1 + (mu - a) t` of minimal multiplicity (`mu = 10`, `e = 7`); for the Iso pair, `h = 1, 17, 85, 265` and `a = 5` give `N = 1, 12, 10, 0`; for the W8 pair, the quadric-scheme values `h = 1, 24, 156, 600, 1725` of `k[y]/K2` (not certified values of `F`) and `a = 6` give `N = 1, 18, 27, 4, 0`. A terminating nonnegative numerator is a prediction and no Cohen-Macaulay certificate.
- [I] The sufficient half needs the Hilbert function of `F/(l_1, ..., l_a) F` for `a` general linear forms, the analytic spread and `e(F)`, none of which the current pipeline outputs. Remark 2.2 turns a Cohen-Macaulay verdict into a reduction number (the degree of `N`), which bounds the degrees of the relations of `F`.
