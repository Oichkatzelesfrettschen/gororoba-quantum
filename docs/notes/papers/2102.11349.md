## Statements

- [P] Abstract and Contributions (p. 2): with an oracle that returns M x for x in F_q^m (the Mv oracle), computing the trace, the determinant, solving A x = b over F_q^(n x n), and testing rank(M) = n against rank(M) <= n/2 each need Omega(n) quantum queries; O(n) queries suffice classically to learn the whole matrix, so no asymptotic quantum speedup exists for these problems.
- [P] Table 1 (p. 4): quantum rank testing costs Theta(min{m, n}) queries over F_q to distinguish rank <= (1/2) min{m, n} from full rank (Theorem 4.16); trace and linear regression cost Theta(n) (Theorems 4.5 and 4.13).
- [P] Theorem 3.1 (cited p. 3): left and right matrix-vector queries have identical quantum query complexity; Theorem 3.7 (cited p. 3): the Mv and vector-matrix-vector oracles are equivalent in the quantum model.
- [P] Contributions (p. 2): the same paper gives exponential quantum speedups for row and column parities and for deciding identical rows or columns over F_2, so the lower bounds are specific to linear-algebra functionals, not a statement that Mv access is weak.
- [P] Page 2 cites van Apeldoorn and Gribling for the problem over F_p of deciding full rank against nullity 1 by matrix-vector queries (their reference 21; see the staged note for arXiv 1810.12030).
- Theorem numbers for the determinant and linear-system bounds sit past page 5: verify.

## Mapping to this repository

- [I] The finding that no quantum algorithm beats exact elimination for F_p ranks at the fiber program's sizes has a rigorous query-model anchor: over F_q the rank-testing bound is linear in the dimension, the same order as classical Gaussian elimination's query count.
- [I] Caveat: the bound assumes oracle access to an unknown M. The kernel-map circuit in `pathion_kernel_map.py` compiles a fully known operator (a two-term signed-permutation sum whose nullity `cd_core` computes exactly), so the theorem bounds a hypothetical quantum rank solver and does not describe the circuit's cost. The circuit is a known-answer device probe.
- [I] The fiber program's truncated-rank matrices are given by explicit generators, not by an Mv oracle; the bound therefore reads as evidence of structural parity with classical cost, not as a bound on an algorithm that exploits the generator structure.
