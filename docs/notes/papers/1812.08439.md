## Statements read

- [P] Abstract (p. 1): the exceptional simple Lie algebras of types `E_7` and `E_8` are endowed with optimal `SL_2`-structures and are described in terms of the corresponding coordinate algebras, nonassociative algebras that resemble code algebras.
- [P] Introduction (p. 1): the `E_8` root lattice is obtained from the extended Hamming `[8, 4, 4]` binary linear code, and the `E_7` root lattice from the simplex `[7, 3, 4]` code dual to Hamming's `[7, 4, 3]` code. Code algebras are a recently defined class of commutative nonassociative algebras that contain a family of orthogonal idempotents with a Peirce decomposition. Vinberg introduced S-structures as an extension of grading by an abelian group. The Lie algebras of Freudenthal's Magic Square, including `F_4, E_6, E_7, E_8`, were described in terms of simple components and triality, and the paper recasts that description with optimal short `SL_2^n`-structures.
