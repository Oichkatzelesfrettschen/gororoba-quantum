## Main claims and evidence

- [P] Robust phase estimation gauges amplitude and off-resonance errors of a single-qubit gate set with Heisenberg scaling, without entanglement, and robustly to state preparation and measurement error.
- [P] The erratum, carried inline in arXiv v3, corrects the per-iteration error condition from pi/(2 k_j) to pi/(3 k_j).

## Mapping to this repository

- [I] Targeted estimation of one systematic phase needs far fewer shots than tomography; a robust-phase-estimation schedule is a candidate for a later window-phase estimate.
