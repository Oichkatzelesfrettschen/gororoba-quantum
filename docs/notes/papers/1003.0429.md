## Transcribed statements

Read from the PDF above; page numbers are the printed page numbers, which equal the PDF page
indices. Paper index `i` runs from 1 to `n` over the coordinates of `x` and `y` in `(Z_2)^n`.

- [P] Eq. 1.1 (p. 2): the twisted product `u_x . u_y = (-1)^f(x, y) u_(x+y)` on `K[(Z_2)^n]`, with
  `f` a two-argument function on `(Z_2)^n` valued in `Z_2`.
- [P] Octonion product (p. 3): `u_(x1,x2,x3) . u_(y1,y2,y3) = (-1)^(x1 x2 y3 + x1 y2 x3 + y1 x2 x3 + sum_(1<=i<=j<=3) x_i y_j) u_(x1+y1, x2+y2, x3+y3)`.
  The paper adds that the twisting function "is a polynomial of degree 3, and does not define a
  2-cocycle", equivalent to the non-associativity of `O`.
- [P] Eq. 1.3 (p. 4): `f_O(x, y) = sum_(1<=i<j<k<=n) (x_i x_j y_k + x_i y_j x_k + y_i x_j x_k) + sum_(1<=i<=j<=n) x_i y_j`,
  the twisting function of the complex algebras `O_n`, "for arbitrary n".
- [P] Eq. 1.4 (p. 4): `f_M(x, y) = sum_(1<=i<j<k<=n) (x_i x_j y_k + x_i y_j x_k + y_i x_j x_k)`, "just the
  homogeneous part of degree 3 of the function f_O".
- [P] Eqs. 2.2 to 2.4 (p. 6): `u_x . (u_y . u_z) = (-1)^phi(x, y, z) (u_x . u_y) . u_z` and
  `phi(x, y, z) = f(y, z) + f(x + y, z) + f(x, y + z) + f(x, y)`, which "reads `phi = delta f`".
- [P] Definition 3.1, Eqs. 3.1 and 3.2 (p. 9): a function `alpha : G -> Z_2` is a generating function
  when `beta(x, y) = alpha(x + y) + alpha(x) + alpha(y)` and
  `phi(x, y, z) = alpha(x + y + z) + alpha(x + y) + alpha(x + z) + alpha(y + z) + alpha(x) + alpha(y) + alpha(z)`.
- [P] Section 3 opening (p. 9): the generating function "allows to distinguish the Clifford algebras,
  octonions and the two new series we introduce in this paper from other twisted group algebras over
  `(Z_2)^n` (such as Cayley-Dickson algebras)". The introduction (p. 5) says existence of a generating
  function "is a way to distinguish the series `O_n` and `M_n` from the classical Cayley-Dickson algebras".
- [P] Theorem 2 (p. 13): for a `(Z_2)^n`-graded quasialgebra, "the function phi is symmetric" and
  "the algebra A has a generating function" are equivalent.
- [P] Proposition 4.1 (p. 13): "Given a function alpha : (Z_2)^n -> Z_2, there exists a twisted group
  algebra A such that alpha is a generating function of A, if and only if alpha is a polynomial of
  degree <= 3." The proof is in Section 6.2 (unread).
- [P] End of Section 4.1 (p. 13): "Let us notice that the Cayley-Dickson algebras are not of this type,
  cf. [4]", where "this type" is a twisted group algebra with symmetric `phi = delta f` (Eq. 4.1) and
  reference [4] is Albuquerque and Majid.

## Main claims

- [P] The paper studies twisted group algebras over (Z_2)^n with cubic twisting
  functions. The octonions carry f(x, y) = x1 x2 y3 + x1 y2 x3 + y1 x2 x3 +
  sum_(1 <= i <= j <= 3) x_i y_j, of degree 3, and the series O_n takes the same form
  for every n (Eq. 1.3); M_n keeps only the cubic part (Eq. 1.4).
- [P] A generating function alpha : (Z_2)^n -> Z_2 encodes an algebra when one exists;
  Proposition 4.1 states that alpha is the generating function of some twisted group
  algebra exactly when alpha is a polynomial of degree at most 3. The introduction and
  Section 3 use the existence of a generating function to separate O_n, M_n, the Clifford
  algebras and the octonions from the Cayley-Dickson algebras, and Section 4 notes that
  the Cayley-Dickson algebras do not have a symmetric associator phi = delta f, citing
  Albuquerque and Majid.
- [P] No degree is stated for the Cayley-Dickson twisting function beyond the octonions.
