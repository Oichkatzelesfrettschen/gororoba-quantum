## Statements

- [P] Abstract (p. 1): under quantum-inspired sampling-and-query access, classical algorithms perform singular value transformation in time independent of the input dimension, which removes the exponential quantum speedup of QSVT in the corresponding QRAM input model for close-to-low-rank matrices.
- [P] Theorem 5.1 (p. 27, even singular value transformation) and Theorem 7.1 (p. 56, generic singular value transformation): the classical SVT statements for `A` given through `SQ(A)` and `SQ(A^dagger)` with Lipschitz `f`.
- [P] Theorem 7.2 (p. 59): eigenvalue transformation of a Hermitian `A` given through `SQ_phi(A)`.
