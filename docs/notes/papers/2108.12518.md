## Main claims and evidence

- [P] M3 corrects in the subspace spanned by the noisy output bit strings, accommodates uncorrelated and correlated errors and returns error bounds (abstract).
- [P] Elements of the calibration matrix are formed directly from bit-string values, and the number of single-qubit calibration matrices scales at most linearly with the number of qubits; correlated errors enter through an equivalent expression, with an appendix example that induces correlated errors deliberately.
- [P] A matrix-free preconditioned iterative solver converges in O(1) steps and mitigates errors in seconds on qubit counts that direct inversion cannot handle.

## Limits

- [P/I] The calibration still represents the noisy measurement as one assignment matrix; context dependence beyond that matrix is out of scope.
- [P/I] Correct to first order only for errors that are stationary between the calibration and the target run.
