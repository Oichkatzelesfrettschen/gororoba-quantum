## Transcribed statements

Definition of skew [P] (p. 2): "a Hadamard matrix is skew if `H - I` is a skew-symmetric matrix". This is the same
definition as the one on PDF page 62 of [Kivunge](kivunge-2013-sign-matrices-2n-ons.md).

- [P] Abstract (p. 1) and Section 1 (pp. 1-2): quaternary unit Hadamard (QUH) matrices were introduced by Fender,
  Kharaghani and Suda; the paper gives a construction of real Hadamard matrices from QUH matrices, recovers
  Mukhopadhyay's real Hadamard matrices of order `q^n + q^(n-1)` for each prime power `q = 3 mod 4`, and proves
  nonexistence conditions for QUH matrices. "We construct a morphism from QUH matrices onto real Hadamard
  matrices, using skew-Hadamard matrices."
- [P] Proposition 1 (p. 2): for a skew-Hadamard matrix `H` of order `m + 1` with `m + 1` not a perfect square,
  the minimal polynomial of `alpha_m = (1 + sqrt(-m))/sqrt(m + 1)` and the minimal polynomial of `H/sqrt(m + 1)`
  both equal `m(x) = x^4 + (2(m - 1)/(m + 1)) x^2 + 1`. The proof uses `H H^T = (m + 1) I` and `H^T = 2I - H`,
  which give `H^2 = 2H - (m + 1) I`. For `m + 1` a perfect square the polynomial factors into two irreducible
  quadratics over `Q` (p. 3).
- [P] Proposition 2 (p. 3): "If `H` is a skew-Hadamard matrix of order `m`" the `Q`-algebras `Q[x]/(m(x))`,
  `Q(H/sqrt(m + 1))` and `Q[alpha_m]` are isomorphic. As printed the statement says order `m`, while
  Proposition 1 and Theorem 4 use order `m + 1`.
- [P] Definition 3 (p. 3): a QUH matrix is an element of `H(n, X_m)`, the `n x n` Hadamard matrices over
  `X_m = {(+-1 +- sqrt(-m))/sqrt(m + 1)}`.
- [P] Theorem 4 (p. 3), the definition of the morphism: if a skew-Hadamard matrix `H` of order `m + 1` exists and
  `m + 1` is not a perfect square, there is a morphism `H(n, X_m) -> BH(nm + n, 2)`. The map is the field
  isomorphism `phi : Q(alpha_m) -> Q(H/sqrt(m + 1))` with `phi(alpha_m) = H/sqrt(m + 1)` and
  `phi(alpha_m^*) = H^T/sqrt(m + 1)`, applied to every entry of a QUH matrix `M` to give the block matrix `M^phi`
  of size `n(m + 1)`; `sqrt(m + 1) M^phi` is a real Hadamard matrix. The proof uses that `phi` is a ring
  isomorphism, so inner products of columns map to `n delta_ij I`. The paper calls the isomorphism "a morphism of
  complex Hadamard matrices".
- [P] p. 4, the alternative argument: write a QUH matrix as `(1/sqrt(m + 1)) A + (sqrt(-m)/sqrt(m + 1)) B` with
  `A, B` matrices of `+-1` of order `n`; then `A B^T = B A^T` and `A A^T + B B^T = n(m + 1) I_n`; substituting `A`
  for the diagonal entries of a skew-Hadamard matrix `M` of order `m + 1` and `+-B` for its off-diagonal `+-1`
  entries gives a Hadamard matrix of order `n(m + 1)`.
- [P] Theorem 5 (p. 4, cited from Section 3 of Fender, Kharaghani and Suda): for a prime power `q = 3 mod 4`,
  `A_0 = B_0 = 1`, `A_t = J_q (x) B_(t-1)`, `B_t = I_q (x) A_(t-1) + Q (x) B_(t-1)` with `Q` the `q x q`
  Jacobsthal matrix; then `(1/sqrt(q + 1)) A_t + i (sqrt(q)/sqrt(q + 1)) B_t` lies in `H(q^t, X_q)`.
- [P] Corollary 6 (p. 4): for every `n >= 1` a real Hadamard matrix of order `q^n + q^(n-1)` exists; the paper
  notes that "the Paley matrix of order `q + 1` is skew" and credits Mukhopadhyay and Seberry for the result.
- [P] Theorem 13 (pp. 6-7): for odd `n` with squarefree part `t` and a prime `p = 3 mod 4` whose `p + 1` has
  squarefree part `s > 1`, if an odd prime `q` divides `t` with `(s/q) = 1` and `(-p/q) = -1`, then `H(n, X_p)` is
  empty. The Galois group of the splitting field `K = Q(sqrt(-m), sqrt(m + 1))` is elementary abelian of order 4
  (p. 5).

## Mapping to this repository

- [I] The paper's "morphism" is a map between sets of Hadamard matrices induced by a field isomorphism applied
  entrywise; it carries no homomorphism of automorphism groups and no signed-permutation or Hadamard-equivalence
  map, so the repository's signed-permutation certificate (`T(e_i e_j) = T(e_i) T(e_j)` on basis pairs) has no
  object here. The paper holds no octonion, sedenion or Cayley-Dickson statement and no `PSL(2, 7)` statement.
- [I] Overlap: the sign matrices of the `cd_core` basis products are skew Hadamard matrices in this paper's
  sense. A scratch check under the ignored `docs/local/` forms `H = diag(1, -1, ..., -1) * [cd_sign(n, i, j)]` for
  `n = 2, 4, ..., 64` and confirms for each `n` that `H - I` is skew-symmetric, `H^2 = 2H - nI` and
  `H^4 + 2(n - 2) H^2 + n^2 I = 0` (the relation of Proposition 1 with `m = n - 1`), all in integer arithmetic.
  `n` is a perfect square for `n = 4, 16, 64`, where Proposition 1 does not apply, and not a perfect square for
  `n = 2, 8, 32`. The repository already carries this skew-Hadamard property as a proved result for every `n`
  ([cd-star-lattice-tower](../topics/cd-star-lattice-tower.md#the-boundary-as-a-paley-matrix)), so the check adds
  the minimal-polynomial relation only.
- [I] Application: at `n = 8` the matrix is the order-8 case `m = 7 = q` of Theorem 4 and Corollary 6
  (`q + 1 = 8`), and the repository's note records `W_8` as signed-permutation equivalent to the Paley matrix of
  `q = 7`. A QUH matrix in `H(n, X_7)` would therefore map to a real Hadamard matrix of order `8n`, with `phi`
  taken from the order-8 sign matrix; the repository has not constructed one.
