## Main claims and evidence

- [P] Virtual Z gates shift the phase of all later drives, have zero duration, and with two X(pi/2) pulses generate any SU(2) gate.
- [P] Virtual Z gates correct unitary rotation errors; combined with DRAG (DRAGZ) they give a 13.3 ns X(pi/2) with error 1.95e-4.

## Mapping to this repository

- [I] A characterized static window phase admits a compensating virtual Z as one candidate intervention for the frozen validation stage.
