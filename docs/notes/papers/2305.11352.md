## Statements

- [P] Abstract (p. 1): filtering and Poissonization bring the randomized adiabatic solver to the optimal O(kappa log(1/epsilon)); a randomized walk operator replaces Hamiltonian simulation; a closed formula bounds the expected number of block-encoding calls, 837 kappa at epsilon = 10^-10 for Hermitian matrices.
- [P] Theorem 1 (pp. 2-3, optimal QLSA with explicit counts): for `A` scaled so its singular values lie in [1/kappa, 1], a randomized algorithm outputs a state epsilon-close in 1-norm to `|A^-1 b>` using an expected Q* = O(kappa log(1/epsilon)) calls to the controlled block encoding `U_A` and 2 Q* calls to `U_b`.
