## Statements

- [P] Section 1 (p. 2): the rank problem asks whether rank A >= r for an n x m matrix; Dorn and Thierauf show an Omega(n^2) quantum query lower bound for the determinant and hence the rank problem, so the paper studies a promise version through a high-level span program reduced to an ordinary span program.

## Mapping to this repository

[I] The Dorn-Thierauf Omega(n^2) query bound it cites means exact rank, the quantity the A_5 truncated ranks compute, admits no query-complexity speedup in general ([quantum linear algebra against the A_5 fiber computations](../topics/quantum-linear-algebra-fit-a5.md)).
