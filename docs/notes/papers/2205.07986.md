## Transcribed statements

Read from the PDF above; page numbers are the printed page numbers, which equal the PDF page
indices. The text layer drops overbars, so Eq. 2.1 was read from the rendered page 3. Bit sequences
use the paper's `A = a_0 2^0 + ... + a_(n-1) 2^(n-1)`, so bit 0 is the lowest bit and the newest
Cayley-Dickson generator `g_n` sits on the highest bit.

- [P] Eq. 2.1 (p. 3), the doubling rule: for `a, b, c, d` in `D^(n)`,
  `(a + b g_n)(c + d g_n) = (a c - conj(d) b) + (d a + b conj(c)) g_n`, with `g_i^2 = -1` and
  `conj(g_i) = -g_i` for the generators `g_0, ..., g_(n-1)`.
- [P] Convention (2.13) (p. 3): products of generators are taken from left to right,
  `g_(i0) g_(i1) ... g_(ik) := ((g_(i0) g_(i1)) g_(i2)) ... g_(ik)`.
- [P] Definition 1, Eq. 2.14 (p. 3): for `A = a_0 2^0 + a_1 2^1 + ... + a_(n-1) 2^(n-1)` with every
  `a_i` in {0, 1}, `e_A := g_0^(a_0) g_1^(a_1) ... g_(n-1)^(a_(n-1))`.
- [P] Lemma 3, Eq. 3.2 (p. 4): there is a map `sigma : Z x Z -> Z_2` with
  `e_A e_B = (-1)^sigma(A, B) e_(A XOR B)`, where `XOR` is the bitwise sum of Definition 3.
- [P] Proposition 1, Eq. 3.3 (p. 4): for `0 <= A, B <= 2^n - 1` and `a_n, b_n` in {0, 1},
  `sigma(A + a_n 2^n, B + b_n 2^n) = sigma(A, B)(1 + b_n) + sigma(B, A) b_n + sigma(B, B) a_n + a_n b_n`.
  The proof (p. 5) derives `sigma(A + 2^n, B) = sigma(A, B) + sigma(B, B)` from Eq. 2.5,
  `sigma(A, B + 2^n) = sigma(B, A)` from Eq. 2.10 and
  `sigma(A + 2^n, B + 2^n) = 1 + sigma(B, B) + sigma(B, A)` from Eq. 2.12. Section 3 (p. 4) credits the
  recursion to Albuquerque and Majid, reference [1].
- [P] Definition 4 (p. 5): for a positive integer `A = a_0 2^0 + a_1 2^1 + ... + a_n 2^n`,
  `deg A := min{ i >= 0 : a_i != 0 }`.
- [P] Definition 5 (p. 5): `phi(a, b) = a + b + ab` on `Z_2 x Z_2`, and
  `l = l(A, B) := max{ deg A, deg B, deg(A XOR B) }`. The introduction (Eq. 1.5, p. 2) states the same
  function as `phi(a, b) = 0` if `a = b = 0` and `1` otherwise.
- [P] Theorem 1, Eq. 4.1 (p. 7): in `e_A e_B = (-1)^sigma(A, B) e_(A XOR B)` of `D^(n)`,
  `sigma(A, B) = 0` if `AB = 0`; `1` if `A = B != 0`; and for `A != B`, `AB != 0`:
  `b_l + sum_(i = l)^(n-1) phi(a_i, b_i)` if `deg A > deg B`;
  `1 + a_l + sum_(i = l)^(n-1) phi(a_i, b_i)` if `deg A < deg B`;
  `a_l + sum_(i = l)^(n-1) phi(a_i, b_i)` if `deg A = deg B`;
  with `A`, `B` as in Eqs. 1.2 and 1.3, `phi` as in Eq. 1.5 and `l` as in Eq. 1.4. The same statement
  opens the paper as Eq. 1.1 (p. 2).

## Main claims

- [P] The algebra D(n) doubles by Eq. 2.1, and e_A is the left-to-right product of the generators
  g_i^(a_i) (Definition 1), so e_A e_B = (-1)^sigma(A, B) e_(A XOR B).
- [P] Proposition 1 derives the recursion for sigma from Eqs. 2.5, 2.10 and 2.12, crediting the
  recursion to Albuquerque and Majid.
- [P] Theorem 1: with deg A the lowest set bit of A (Definition 4) and l = max(deg A,
  deg B, deg(A XOR B)), sigma vanishes when AB = 0, equals 1 when A = B != 0, and for
  distinct nonzero A, B equals b_l + c, 1 + a_l + c or a_l + c as deg A >, < or = deg B,
  where c = sum_(i = l)^(n-1) phi(a_i, b_i) and phi(a, b) = a + b + ab.
- [P] Section 5 gives the split Cayley-Dickson twist through the relation between the two
  algebras. No degree, Walsh spectrum or ANF statement appears.

## Mapping to this repository

- [I] Convention map: sigma_RZ(A, B) = [cd_sign(2^n, A, B) = -1] = phi_n(A, B), the
  untransposed convention, so the Proposition 1 recursion is Corollary 4.3 of
  Albuquerque and Majid with its arguments exchanged, F_AM(a, b) = cd_sign(b, a)
  ([math-9802116.md](../math-9802116.md)). `check_closed_form` in
  [cd_phase_degree.py](../../../scripts/cd_phase_degree.py) (gate core-320) requires
  Theorem 1 to equal the cd_sign table on every pair through n = 8 and its transpose to
  differ from n = 2 on.
- [I] Theorem 1 states the sign rows in closed form and no degree. The exact degrees of
  [cd_phase_degree.md](../cd_phase_degree.md), n - 1 for every left row, the leading layer
  sum_j m_j prod_(l != j) x_l and max(1, bitlen(m) - 2) for the right rows, are not stated
  there; the closed form makes the OR-shaped dependence on the bits above the lowest set
  bit visible, which the degree proofs reach through the recursion instead.
- [I] The twisted-group-algebra constructions of Bales 2011 ([1107.1375.md](1107.1375.md)) and
  Flaut and Boboescu 2021 ([2103.12805.md](2103.12805.md)) state no degree, ANF or Walsh property of
