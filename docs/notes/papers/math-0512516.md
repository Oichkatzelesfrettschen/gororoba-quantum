## Statements and hypotheses

- [P] Setting (pp. 1-2). `A_n = R^(2^n)` with `(a, b)(x, y) = (a x - conj(y) b, y a + b conj(x))`; `Aut(A_1) = Z/2`,
  `Aut(A_2) = SO(3)`, `Aut(A_3) = G2`, and for `n >= 4` `Aut(A_n) = Aut(A_(n-1)) x S_3` after Eakin and Sathaye (p. 1). An
  algebra monomorphism `phi : A_m -> A_n` is linear with `phi(e0) = e0` and `phi(x y) = phi(x) phi(y)`; it is
  isometric on imaginary parts (p. 6). The set is `M(A_m, A_n)`; `M(A_n, A_n) = Aut(A_n)`.
- [P] Section 1 (pp. 3-5): doubly pure elements `a~ = a ee0` with `ee0 = e_(2^n)` in `A_(n+1)`. Lemma 1.1 states `a ee0 = a~`,
  `a a~ = -|a|^2 ee0`, `a~ b = -(a b)~` for pure `a` and doubly pure `b`, and (item 6) `(a b)~ = a b~` exactly when `a` is
  orthogonal to `b` and `a~` is orthogonal to `b`; Corollary 1.2: `H_a = span{e0, a~, a, ee0}` is a copy of the quaternions
  for nonzero doubly pure `a`.
- [P] Proposition 2.1 (p. 6): `M(A_1, A_n) = S(Im A_n) = S^(2^n - 2)`. Lemma 2.2 (p. 7): for orthonormal pure `a, b` with `a`
  alternating strongly with `b`, `V(a; b) = span{e0, a, b, ab}` is the quaternions. Proposition 2.3 (p. 7):
  `M(A_2, A_n) = {(a, b) in V_(2^n - 1, 2) : a ! b}`, giving `M(A_2, A_3) = V_(7,2)` and `Aut(A_2) = V_(3,2) = SO(3)`.
- [P] Special triples (p. 8): an orthonormal set `{a, b, c}` of pure elements with pairwise strong alternation and
  `c` orthogonal to `V(a; b)`. Proposition 2.4 (p. 8): for a special triple, `O(a; b; c) = span{e0, a, b, ab, c(ab), cb, ac, c}`
  is an eight-dimensional subalgebra isomorphic to the octonions, and `M(A_3, A_n)` is the set of special triples. For
  `n = 3` the assignment `(a, b, c) -> (a, b)` is the fibration `G2 -> V_(7,2)` with fiber `S^3`.
- [P] Type I and type II (pp. 2-3, 9-10): a monomorphism into `A_(n+1)` is type I when `e_(2^n)`, written `ee0`, is in the
  image, and type II when additionally `eps = e_(2^(n-1))` is. `M_1(A_1, A_n) = S^1`, `M_1(A_2, A_n) = S(Im~ A_n) = S^(2^n - 3)`,
  and `S^5 = M_1(A_2, A_3)` is the bottom cell of `V_(7,2)` (p. 10).
- [P] Theorem 2.5 (pp. 3, 10-11), the main result: for `n >= 3`, `M_2(A_3, A_(n+1)) = CP^(2^(n-1) - 1) union X_n`, with
  `X_n = {(x, y) in Im~ A_n x Im~ A_n : x y = 0, x != 0, y != 0}`; `X_3` is empty, so `M_2(A_3, A_4) = CP^3`. The proof
  (p. 11) writes `alpha = (a, b)` in `H_eps^perp`, shows `(alpha, alpha, eps) = (0, (a, ee0, b))` and `(a, ee0, b) = 2 a~ d` for
  the component `d` of `b` in `H_a^perp`, so the image is an octonion subalgebra exactly when `a d = 0`; either `d = 0`
  (then `b` lies in the complex line spanned by `a`, `a~`) or `(a, d)` lies in `X_n`.

## Convention map and cd_core check

[I] Product. With bars restored, the printed doubling is `cd_core`'s
`(a,b)(c,d) = (ac - conj(d) b, d a + b conj(c))`; the XOR basis index is the paper's `e_(2^n + i) = (0, e_i)`. The note on
[math-0512517](../math-0512517.md) records the same convention for the companion paper.

[I] Check results: no mismatch. A scratch script (ignored `docs/local/`, run with `-I`) tested Theorem 2.5 with exact
rational arithmetic at the levels `n = 3` (`D = 16`) and `n = 4` (`D = 32`), with `eps = e4` or `e8`, `ee0 = e8` or `e16`:

| Paper statement | Result under `cd_core` |
| --- | --- |
| `D = 16`: type II image from a complex line, `b` in `span{a, a~}` | `(alpha, alpha, eps) = 0`; the eight generators span a closed 8-dimensional subspace |
| `D = 16`: generic `alpha` in `H_eps^perp` is not type II | `(alpha, alpha, eps) != 0` for 40 of 40 random elements |
| `D = 32`: zero-divisor branch, `alpha = (e1 + e10, e4 - e15)` with `(e1 + e10)(e4 - e15) = 0` in `A_4` | `(alpha, alpha, eps) = 0`; the eight generators span a closed 8-dimensional subspace; 0 alternativity failures on 30 random pairs of its elements |
| `D = 32`: `alpha = (e1 + e10, e4)` (`a d != 0`) | `(alpha, alpha, eps) != 0` |
| `D = 32`: generic `alpha` in `H_eps^perp` | `(alpha, alpha, eps) != 0` for 20 of 20 random elements |

[I] The identification of the `d = 0` branch with `CP^(2^(n-1) - 1)` is not argued in the paper: the proof shows only that
`(a, b)` with `b` in `span{a, a~}` determines a complex line in `Im~ A_n`, and the set of such pairs is not a projective
space. The octonion subalgebra of a type II monomorphism is also determined by `alpha` only up to the `S^3` action of
[math-0404172](math-0404172.md) Theorem 3.8. The checks above test the dichotomy `d = 0` or `a d = 0`, not the topology.

## Repository bearing

[I] Zero divisors and Stiefel elements. Theorem 2.5 realizes every pair `(a, d)` of doubly pure elements of `A_n` with
`a d = 0` as an eight-dimensional octonion subalgebra of `A_(n+1)` containing `e_(2^(n-1))` and `e_(2^n)`; the
repository's Design B pair `(e1 + e10)(e4 - e15) = 0` is such a pair (check above), so its image under the `n = 4` rule is a
zero-divisor-free octonion copy in dimension 32. The set `X_n` is the equal-halves case of the zero divisors of
`A_n`; Moreno's Stiefel question (`math/0512517` Section 5) concerns the larger Stiefel set of pairs `(a, b)` with `a` and `b`
pure, orthogonal and of equal norm, which this paper does not treat. Answers in the repository: `a5-stiefel-universal`
(every nonzero `A_5` Stiefel element is a zero divisor) and `a6-stiefel-witness` with `a6-stiefel-generic-invertibility`
(an `A_6` Stiefel element that is not a zero divisor).

[I] Other claims in `docs/state/research_state.json`: `sedenion-g2-bundle` (the sedenion zero-product pair space with
bundle `SU(2) -> G2 -> V_2(R^7)`) is the `n = 3` case of the fibration `G2 -> V_(7,2)` with fiber `S^3` in Proposition
2.4. `dimension32-global-topology`: none, because the paper gives no rank strata. Dimensions 64 and above: Theorem 2.5 holds
for every `n >= 3`, so it covers `A_(n+1)` for the 64- and 128-ions with `X_n` the zero divisors of the previous level;
no counts or topology are computed.
