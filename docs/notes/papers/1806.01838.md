## Main claims

[P] Polynomials of the singular values of a block of a unitary can be implemented with a number of uses of the unitary equal to the polynomial degree, and block-encodings supply a toolbox for sums and products of matrices.

- [P] Projected unitary encoding (Sec. 1): for orthogonal projectors Pi and Pi~ and a unitary U, the operator A = Pi~ U Pi is encoded. Block-encoding is the case Pi = Pi~ = |0><0|^a tensor I, where A is the top-left block of U.
- [P] Theorem 17 and Lemma 19: for an odd or even real polynomial P of degree n bounded by 1 on [-1, 1], the singular value transformation P^(SV)(A) is implemented with n uses of U and U^dagger, n uses each of the Pi-controlled NOT and Pi~-controlled NOT gates, n single-qubit phase gates, and one ancilla qubit. The Pi-controlled NOT is X tensor Pi plus I tensor (I - Pi) (Definition 2).
- [P] Definition 43 (p. 41): an (s+a)-qubit unitary U is an (alpha, a, epsilon)-block-encoding of the s-qubit operator A if || A - alpha (<0|^a tensor I) U (|0>^a tensor I) || <= epsilon. The paper notes that ||U|| = 1 forces ||A|| <= alpha + epsilon, and that a matrix of size n x m with n, m <= 2^s embeds faithfully into a 2^s x 2^s matrix by zero padding, which respects sums and products.
- [P] Sec. 4.1 remark: for a block-encoding the Pi-controlled NOT is a Toffoli gate on a+1 qubits, implementable with O(a+1) two-qubit gates and one additional ancilla (ref. HLZ+17).
- [P] Definition 44, Lemmas 45-50: trivial block-encoding of a unitary as (1, 0, 0); of a density operator from a purification (Lemma 45); of a POVM element (Lemma 46); of a Gram matrix A_ij = <psi_i|phi_j> from state-preparation unitaries U_L^dagger U_R as (1, a, 0) (Lemma 47); of a row-sparse and column-sparse matrix from sparse-access oracles (Lemma 48); a preamplified variant (Lemma 49); and matrices in a quantum data structure (Lemma 50).
- [P] Lemma 48: for A in C^(2^w x 2^w), sr-row-sparse and sc-column-sparse with entries of modulus at most 1, with oracles O_r, O_c and an entry oracle O_A, there is a (sqrt(sr sc), w + 3, epsilon)-block-encoding using one use each of O_r and O_c, two uses of O_A, and O(w + log^2.5(sr sc / epsilon)) one- and two-qubit gates and O(b, log^2.5(sr sc / epsilon)) ancillas for b-bit entries.
- [P] Definition 51 and Lemma 52 (linear combination): with a (beta, b, epsilon1) state-preparation pair (P_L, P_R) for y and (alpha, a, epsilon2)-block-encodings U_j of A_j, A = sum_j y_j A_j has an (alpha beta, a + b, alpha epsilon1 + alpha beta epsilon2)-block-encoding with a single use of the select unitary W, P_R, and P_L^dagger. Every term carries the same alpha.
- [P] Lemma 53 (product): an (alpha, a, delta)-block-encoding of A and a (beta, b, epsilon)-block-encoding of B give an (alpha beta, a + b, alpha epsilon + beta delta)-block-encoding of AB, with the ancilla registers kept separate. Lemma 54 and Corollary 55 reuse the ancillas for unitary factors at an error that grows at most quadratically with the number of factors (4 K^2 epsilon).
- [P] Theorem 56 (arbitrary-parity polynomials) requires an (alpha, a, epsilon)-encoding of a Hermitian matrix and gives an (1, a + 2, ...)-encoding of P(A/alpha) with d uses of U and one controlled use.
- [P] Theorem 32: singular value discrimination of a singular vector with value at most a or at least b needs degree O(1 / max[b - a, sqrt(1 - a^2) - sqrt(1 - b^2)] log(1/epsilon)).
- [P] Theorem 73 (Sec. 6): eigenvalue transformation of an unknown Hermitian block-encoding by f needs Omega((|f(x) - f(y)| - 2 epsilon) / |x - y|) uses of the block-encoding.
- [P] The paper has no octonion, Jordan-algebra, or hardware content and no circuit counts for any fixed small matrix.

## Mapping to this repository

- [I] Norm constraint and padding for the Albert observable. Repository claim: literature/notes/topics/open_gororoba_handoff.md, frontier item "Albert observables" -- one verified linearized observable T_{A,B}(X) = (A o B) o X - A o (B o X) as a 27 x 27 linear map to block-encode, where the 27-coordinate description needs an orthonormal basis or the coordinate Gram matrix before proving alpha >= ||T_{A,B}||. Source item: Definition 43 and the zero-padding remark that follows it. Model map: 27 <= 2^5, so T embeds in a 32 x 32 matrix and the system register has s = 5 qubits; the requirement alpha >= ||T|| is the paper's necessary condition ||A|| <= alpha + epsilon. The norm is the operator norm of the matrix in the computational basis of the system register, which the register treats as orthonormal. If the 27 coordinates are not orthonormal for the inner product that defines the physical norm of T, with Gram matrix G, the matrix M in those coordinates has Euclidean norm ||M|| and trace-form norm ||G^(1/2) M G^(-1/2)||, and the two agree only for an orthonormal basis. The Gram matrix of Lemma 47 (inner products of prepared states) is a different object from the coordinate Gram matrix of the handoff. Label: "known theorem reproduced". Not established by the source: which norm the physical statement about T uses, or any value of ||T|| for any Albert-algebra pair.
