## Statements

- [P] Theorem 1 (p. 4, quoted from earlier work): with constant sparsity and target error 0 < epsilon <= 1/11 the QLS query complexity is Omega(kappa log(1/epsilon)).
- [P] Theorem 2 (p. 6): with constant target error the QLS query complexity is Omega(kappa sqrt(s)), where `s` is the sparsity; the proof composes PARITY and OR through unbounded-error query complexity (p. 4).
