## Statements

- [P] Abstract (p. 1): kernel reflection, an extension of eigenstate filtering, solves the QLSP with one reflection when the solution norm is known, query complexity (1 + O(epsilon)) kappa ln(2 sqrt 2 / epsilon); with norm estimation by kernel projection the complexity is O(kappa log log kappa log log log kappa + kappa log(1/epsilon)), and an adiabatic norm-estimation step gives the optimal O(kappa log(1/epsilon)).
- [P] Section 6 (p. 11): the explicit bound of the optimal solver is Q <= 56.0 kappa + 1.05 kappa ln(sqrt(1 - epsilon^2)/epsilon) + 2.78 ln(kappa)^3 + 3.17 block-encoding queries.
- [P] Table (p. 12): the quantum-walk method of earlier work carries the constant 234470 kappa + 4 kappa ln(2/epsilon), against which the kernel-reflection constants compare.
