## Statements

- [P] Theorem 1.1 (p. 2): a quantum algorithm decides whether `F = 0` has a solution and computes one with probability at least 1 - epsilon in gate complexity O~((n^3.5 + T_F^3.5) kappa^2 log(1/epsilon)), with `kappa` the condition number of the system.
- [P] Theorem 1.2 (p. 2): the Boolean-solution variant in O~(n^2.5 (n + T_F) kappa^2 log(1/epsilon)); the algorithm runs HHL on a Macaulay linear system over C built from the Boolean system.
