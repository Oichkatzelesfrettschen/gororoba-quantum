## Main claims and evidence

- [P] Matrix arithmetic is performed with the result encoded in the off-diagonal blocks of a Hamiltonian, using Hamiltonian evolutions of the input operators and at most two ancilla qubits; the suite covers multiplication, addition, inversion, Hermitian conjugation, scaling and singular value transformation.
- [P] A generic matrix A enters through its Hermitian dilation with A and its adjoint in the off-diagonal blocks, "similar to prior work".
- [P] The matrix multiplication uses the Lie-group commutator product formula and its higher-order generalizations attributed to Childs and Wiebe, with an error bound matching the Baker-Campbell-Hausdorff series to third order.

## Mapping to this repository

- [I] The dilation `H_a = |0><1| (x) L_a + |1><0| (x) L_a^T` of [singular_sector_dynamics.md](../singular_sector_dynamics.md) is this encoding for one Cayley-Dickson multiplication operator. For imaginary `a` it equals `(iY) (x) L_a`, so the block qubit's Y eigenvalue is conserved.
