## Statements

- [P] Theorem 1 (p. 4, main result): for kappa >= 31, s >= 5 and 0 < epsilon <= 1/64, the quantum query complexity of QLS in the standard sparse-access model is Omega(kappa sqrt(s) log(1/epsilon)).
- [P] Introduction (p. 2): Low's algorithm reaches O((kappa sqrt(s))^(1+o(1))) at constant error, and block encodings give O(kappa log(1/epsilon)) at constant sparsity, so the joint bound is the strongest dependence the known algorithms allow; the title calls it near-optimal.
