# Product Tour

In Quandela Cloud 2.0, we introduced a new dashboard where you can follow in a glimpse what is available, the status of your credits and running jobs, the available platforms, the latest news, the link to the documentation and far more !

![NewCloud.png](https://cloud.quandela.com/webide/docs-assets/509968432.png)

| | |
| --- | --- |
| **(1)** | On the left hand, a navigation panel that you can hide with the `«` symbol |
| **(2)** | The available computing platforms - click on "View All" or "Platforms" from the navigation panel to see more details. |
| **(3)** | A summary and statistics of the jobs you launched and the most recent ones. Click on "View All" or "Jobs" from the navigation panel to see more details. |
| **(4)** | The latest news from Quandela Cloud team and planned maintenance notifications |
| **(5)** | Your available credits and the last month usage you did - see documentation on "Billing and Subscriptions" |
| **(6)** | Your subscription plan - see documentation on "Billing and Subscriptions" |
| **(7)** | Access to your profile or logout |
| **(8)** | Magic link to contact the support team |
| **(9)** | Application Language - English and French are available - more are coming ! |
| **(10)** | This user documentation |
| **(11)** | Your notifications: for instance, you will receive a notification every time a job is complete - you can configure the application to send you email for each notification |
