## Main claims

[P] The hidden shift of any Boolean function with a trivial period group is found by a quantum algorithm whose expected query count is O(n / sqrt(gamma_f)), with gamma_f the minimum influence, and a uniformly random function has an average-case exponential quantum-classical separation.

- [P] Definition 1 (Boolean hidden shift problem, BHSP): f, g: Z_2^n -> Z_2 with (i) f(x) = f(x + t) for all x only if t = 0, and (ii) g(x) = f(x + s) for some s. The oracles are O_f: |b>|x> -> |b + f(x)>|x> and the same for g.
- [P] Definition 2 and Lemma 1: the influence of v is gamma_(f,v) = Pr_x[f(x) != f(x + v)] and gamma_f = min_v gamma_(f,v). Lemma 1: gamma_(f,v) = sum over u with <v,u> = 1 of Fhat(u)^2, where F = (-1)^f. The displayed minimum does not exclude v = 0, for which gamma_(f,0) = 0; the proof of Theorem 1 takes v nonzero.
- [P] Sampling Subroutine (Fig. 1): prepare |0>|0^n>, apply H on the ancilla and on all n qubits, apply O_f, a Z gate on the ancilla, O_g, then H^n, and measure. The measured pair (b, u) always satisfies <u, s> = b, and the marginal of u is D_f^U(u) = Fhat(u)^2, independent of g (Eq. 2).
- [P] Theorem 1: expected O(n / sqrt(gamma_f)) oracle queries, expected time polynomial in the query count, no error; the quadratic improvement over n / gamma_f comes from amplitude amplification. Corollary 1: under the promise gamma_f >= delta, O(n log(1/epsilon) / sqrt(delta)) queries with failure probability at most epsilon.
- [P] Sec. 1: two extremal cases. For delta functions (f marks exactly one element) the hidden shift is unstructured search: classical Theta(2^n), quantum Theta(sqrt(2^n)). For bent functions the classical cost is Omega(sqrt(2^n)) and the quantum cost O(n), or constant with the dual oracle. Footnote 1: the bounds hold for black-box access to f and g; if f is a known bent function the classical cost is O(n).
- [P] Lemma 2: a classical algorithm that solves a uniformly random BHSP instance (f and s uniform) with probability at least 1/2 makes Omega(2^(n/2)) queries (success bound (t^2 + 1) / (2^n - t^2)). Theorem 2: for f and v uniform, a quantum algorithm uses O(n) queries and polynomial time, because Pr[gamma_f < 1/3] <= exp(-Omega(2^n)).
- [P] Abstract and Sec. 1: the bent case reduces to an abelian hidden subgroup problem through quantum functions; the general case "does not seem to allow such a reduction". Sec. 5: the authors conjecture that the algorithm is optimal up to polynomial factors for every function.

## Mapping to this repository

- [I] Repository claim: "Its phase is the OR of those bits" (gororoba_quantum/verify.py, docstring of check_associator_walsh_hierarchy; the check requires the exact ANF coefficient set, all nonempty monomials over bits 1 through n-2, for n = 3 through 7).
  - Source: Sec. 1 (delta functions as the Grover-extremal case), Definition 1, Definition 2, Lemma 1, Theorem 1.
  - Model map: on the m = n - 2 live bits, OR_m = 1 + delta_0, a complemented delta function; a hidden shift of f + 1 is a hidden shift of f. Bits 0 and n-1 do not appear in the ANF, so e_0 and e_(n-1) are periods of omega_(1, 2^(n-1)) and condition (i) of Definition 1 fails on the full n bits; on the live bits the period group is trivial. For v != 0 on the live bits, gamma_(f,v) = Pr[OR(x) != OR(x + v)] = 2 / 2^m (only x = 0 and x = v differ), so gamma_f = 2^(1-m) and Theorem 1 gives O(m 2^((m-1)/2)) queries, the Grover scaling up to the factor m.
  - Label: new implementation or measurement (the exact-ANF check for n = 3 through 7).
  - Not established by the source: any hidden-shift claim about the associator ladder. The shift group would be translation of the index; the source's extremal case makes that problem unstructured search on the live bits, with classical cost Theta(2^m) and quantum cost Theta(sqrt(2^m)); it does not examine the other pairs (a, b).
- [I] Repository claim: "The higher-degree forms are phase-oracle benchmarks whose nonuniform Walsh spectra fall outside standard HSP coset sampling." (gororoba_quantum/DESIGN_NOTES.md, Design C).
  - Source: Eq. (2) and the statement that D_f^U(u) = Fhat(u)^2 does not depend on g; Abstract (the general Boolean case does not reduce to an abelian hidden subgroup problem).
  - Model map: Design C measures P(y) = |Fhat_omega(y)|^2, the same distribution as the u-marginal of the Sampling Subroutine. The subroutine adds one bit, b = <u, s>, obtained by applying O_f, a Z gate, and O_g to the same ancilla. Without a second, shifted oracle the Design C readout carries no shift.
  - Label: new implementation or measurement (the measured non-flat spectra at dims 16 and 32). The sentence holds relative to abelian coset sampling; the source does not claim a hidden subgroup reduction for non-bent f, and note 1107.2189 places graph-oracle polynomial problems inside a nonabelian hidden subgroup problem.
  - Not established by the source: that Walsh sampling of a single phase block identifies anything beyond the spectrum.
- [I] Repository claim: "uncontrolled phase access identifies f and f + 1; controlled access is an extra resource" (literature/notes/open_gororoba_handoff.md, hidden oracle row).
  - Source: Definition 1 and Fig. 1, which use the bit oracles O_f and O_g.
  - Model map: with ancilla a in |+> and the register in |+>^n, a phase block (-1)^g(x) controlled on a = 0 and a block (-1)^f(x) controlled on a = 1, followed by H on a, produce the state of Eq. (2) up to a sign on the b = 1 branch: the a = 0 and a = 1 components are (F(x + s) + F(x))/2 and (F(x + s) - F(x))/2 before H^n. The Fig. 1 construction therefore corresponds to controlled phase access, not to uncontrolled access. The source proves no equivalence between the two models; this correspondence is the note author's derivation from Eq. (2).
  - Label: known theorem reproduced, as the model assumption of Definition 1 and Fig. 1.
  - Not established by the source: whether uncontrolled phase access to f and to g can solve the problem, and the gate cost of controlling a compiled block.
- [I] No repository claim: Classical lower bounds. Lemma 2 and Theorem 2 give Omega(2^(n/2)) for a uniformly random f and a uniformly random s, with both oracles. No source in this set gives Omega(2^(n/2)) for an explicit function. For a known f the cost is O(n) classically (footnote 1); for delta-type f (the OR rung) it is Theta(2^m) on the m = n - 2 live bits, which exceeds 2^(n/2) for n > 4. The bent-function figure Omega(sqrt(2^n)) in the introduction counts n as the number of input bits; note 0811.3208 records that the Maiorana-McFarland bound proved there is Theta(2^(N/4)) in N input bits.

## Action items

1. State the oracle pair (bit oracles with an ancilla, or controlled phase blocks) and Definition 1 condition (i) before any hidden-shift statement about omega_ab; for the pair (1, 2^(n-1)) restrict to the m = n - 2 live bits first.
2. Compute gamma_f for the live-bit quotient of every pair at n = 4 to 7 by enumeration. Acceptance: gamma_f = 2^(1-m) for the pair (1, 2^(n-1)) at each n, and a table of the other pairs' values with the Theorem 1 query bound n / sqrt(gamma_f).
3. Never write Omega(2^(n/2)) for an associator hidden shift without naming Lemma 2's uniform-random distribution and noting that omega_ab is an explicit member of a family of size 2^(2^(n-1)).
4. Record in any write-up that the Design C readout equals the u-marginal of the Sampling Subroutine, so that a hidden-shift variant needs the second, shifted block in superposition.
