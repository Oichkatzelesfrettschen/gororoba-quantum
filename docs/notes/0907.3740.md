## Main claims and evidence

- [P] Empirical Bernstein bounds give data-dependent, variance-sensitive confidence bounds for bounded variables, with improved constants, and extend uniformly over function classes with polynomial growth.
- [P] Sample variance penalization uses those bounds; under stated conditions its excess risk reaches order 1/n against 1/sqrt(n) for empirical risk minimization.

## Statements used

| Locator | Statement |
| --- | --- |
| Theorem 1, p. 1 | [P] Hoeffding: for i.i.d. Z, Z_1, ..., Z_n in [0, 1] and delta > 0, with probability at least 1 - delta, EZ - (1/n) sum Z_i <= sqrt(ln(1/delta) / (2n)). |
| Section 1, p. 1 | [P] V_n(Z) = (1 / (n (n - 1))) sum_{1 <= i < j <= n} (Z_i - Z_j)^2, the sample variance with denominator n - 1. |
| Theorem 3, p. 2 | [P] Bennett: with the true variance V_Z, EZ - (1/n) sum Z_i <= sqrt(2 V_Z ln(1/delta) / n) + ln(1/delta) / (3n). |
| Theorem 4, p. 2 | [P] Under the conditions of Theorem 1, with probability at least 1 - delta, EZ - (1/n) sum Z_i <= sqrt(2 V_n(Z) ln(2/delta) / n) + 7 ln(2/delta) / (3 (n - 1)). |
| Theorem 10 (4), p. 3 | [P] For n >= 2 independent variables in [0, 1], Pr{ sqrt(V_n(X)) > sqrt(E V_n) + sqrt(2 ln(1/delta) / (n - 1)) } <= delta; (3) bounds the opposite direction. |
| Theorem 11, p. 3 | [P] Theorem 4 holds for independent, not necessarily identically distributed, variables in [0, 1], with E[P_n(X)] in place of EZ. |

[I] Theorem 4 is one-sided at tail delta: its ln(2/delta) already carries
the split between Bennett's inequality and the variance bound. A two-sided
interval applies it to Z and to 1 - Z at delta / 2 each, ln(4/delta). For a
score of range R, Z = (Y - a) / R maps it into [0, 1] and V_n scales by R^2,
so the radius reads sqrt(2 V_n(Y) ln(2/delta) / n) + 7 R ln(2/delta) / (3 (n - 1))
and Theorem 10 (4) reads sqrt(V_n(Y)) <= sqrt(Var Y) + R sqrt(2 ln(1/delta) / (n - 1)).
