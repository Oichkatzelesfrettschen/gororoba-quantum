## Main claims

[P] Hidden shifts of a bent function are found by a quantum computer with O(n) queries, and with two queries when the dual bent function is also available as an oracle, while the classical query cost is exponential for the Maiorana-McFarland class when only the shifted pair is available.

- [P] Definition 1 (Sec. 3): f: Z_2^n -> Z_2 is bent if |fhat(w)| = 2^(-n/2) for every w, with fhat(w) = 2^(-n) sum_x (-1)^(w.x + f(x)). Bent functions exist only for even n. The dual bent function ftilde is defined by 2^(n/2) fhat(w) = (-1)^ftilde(w), and the dual of the dual is f.
- [P] Footnote 1 (p. 3): high nonlinearity is the spectral property (large distance to the linear functions). It does not imply high algebraic degree; many highly nonlinear functions have algebraic degree 2.
- [P] Theorem 1 (Dickson), Lemma 2, Corollary 3: a quadratic f(x) = xQx^t + Lx^t with B = Q + Q^t of rank n (even) is bent, affine transforms of bent functions are bent, and the dual of a quadratic bent function is a quadratic bent function.
- [P] Lemma 4: the Maiorana-McFarland function f(x, y) = x pi(y)^t + g(y), pi a permutation of Z_2^n, g arbitrary, is bent with dual ftilde(x, y) = pi^(-1)(x) y^t + g(pi^(-1)(x)). Dillon's partial spreads (Theorem 5), Dobbertin's class, and trace monomials with Kloosterman sums give further families.
- [P] Sec. 3.3: f is bent iff the derivative Delta_h f(x) = f(x + h) + f(x) is balanced for every nonzero h; the shifted functions x -> (-1)^f(x+s) are mutually orthogonal; {x : f(x) = 1} is a difference set. In the paper's notation R(n, r) is the set of truth tables of polynomials of degree at most r in n variables (argument order opposite to RM(r, m)), and bent functions are those at maximum distance from R(n, 1).
- [P] Definition 2 (oracle model): O_f gives access to two bent functions f and g with g(x) = f(x + s) for one s in Z_2^n; O_{f,ftilde} adds access to ftilde. Access is by the bit oracle |x>|0> -> |x>|f(x)>, converted to a phase oracle (-1)^f(x) by an ancilla in (|0> - |1>)/sqrt(2).
- [P] Theorem 6: with O_{f,ftilde}, a zero-error algorithm finds s with one query to g and one query to ftilde and O(n) quantum operations (Hadamard transform, phase query to g, Hadamard transform, phase query to ftilde, Hadamard transform).
- [P] Theorem 7: with O_f alone, O(n) queries give s with constant success probability, in O(n^2) quantum operations. The proof reduces to an abelian hidden subgroup problem in Z_2^(n+1) with hiding function H(b, x) = F(x) for b = 0 and G(x) for b = 1, where F(x) = sum_y (-1)^f(x+y) |y> is injective as a quantum function because all derivatives of a bent function are balanced. The proof assumes the controlled phase oracle Lambda_1(U_f), built from the bit oracle with Fredkin gates.
- [P] p. 11: the author conjectures, without proof, that implementing one query to ftilde from queries to f takes exponentially many queries in the worst case.
- [P] Theorem 8: for the Maiorana-McFarland class with O_{f,ftilde}, Theta(n) classical queries are necessary and sufficient. A Bernstein-Vazirani recursion over trees of height log n gives a poly(n) quantum cost against superpolynomial (n^(log n)) classical cost.
- [P] Theorem 9: for the Maiorana-McFarland class with O_f alone, Theta(sqrt(2^n)) classical queries are necessary and sufficient, where the function is f(x, y) = x pi(y)^t with x and y in Z_2^n, so the input has 2n bits. The proof shown covers the lower bound (Yao minimax, pi uniform in S_(2^n), s = (0, s_2)); the matching upper bound is stated without a proof.
- [P] Corollary 10: a relativized separation P^O != BQP^O.
- [P] Introduction: for a linear function f(x) = r.x the quantum cost is one query and the classical cost is Theta(n) (Bernstein-Vazirani).

## Mapping to this repository

- [I] Repository claim: "Only the n=3 character carries the standard BV/HSP promise. The higher-degree forms are phase-oracle benchmarks whose nonuniform Walsh spectra fall outside standard HSP coset sampling." (gororoba_quantum/DESIGN_NOTES.md, Design C; the same sentence in gororoba_quantum/FACTORING_NOTES.md, "Hidden quadratic and cubic forms").
  - Source: Definition 1 and Sec. 3.3 (bent iff every nonzero derivative is balanced); Theorems 6 and 7 apply to bent f only.
  - Model map: omega_ab is the associator sign of the pair (a, b) as a Boolean function of the index x in F_2^n. By literature/notes/left_mult_sign_rank.md, omega_ab = s_ab + const with s_ab in H_n and the all-ones vector in H_n, so omega_ab lies in H_n = { g(x') + c xi : g of even weight on F_2^(n-1), c in F_2 }, valid for n >= 3. Every such function satisfies Delta_(e_(n-1)) omega_ab = c, a constant, so a nonzero direction has a non-balanced derivative and omega_ab is not bent, for every pair and every n >= 3.
  - Model map, high-bit pair: for the pair (1, 2^(n-1)) the ANF uses bits 1 through n-2 only (verify.check_associator_walsh_hierarchy requires the exact coefficient set), so both e_0 and e_(n-1) are periods.
  - Label: new implementation or measurement (the repository's measured non-flat spectra for specific rungs). The constant-derivative argument in the model map is the note author's derivation and is not a repository result; it excludes the bent promise for all pairs and all n >= 3.
  - Not established by the source: any algorithm or bound for non-bent f. Theorems 6 to 9 say nothing about the associator family, about shifts that act as the Cayley-Dickson product instead of translation of the index, or about Walsh sampling of a single phase state.
- [I] Repository claim: "uncontrolled phase access identifies f and f + 1; controlled access is an extra resource" (literature/notes/topics/open_gororoba_handoff.md, hidden oracle row).
  - Source: Definition 2 and the proof of Theorem 7, which assumes the controlled oracle Lambda_1(U_f) and builds it from the bit oracle by Fredkin gates; Theorem 6 needs a phase query to g and to ftilde in superposition with no control.
  - Model map: the bit oracle |x>|y> -> |x>|y + f(x)> separates f from f + 1; the uncontrolled phase oracle (-1)^f differs between f and f + 1 by a global phase, so it separates them only after control is added. In Theorem 7 the control selects between the F branch and the G branch of H(b, x).
  - Label: known theorem reproduced, as the model assumption of the proof of Theorem 7; the paper states no stand-alone theorem on uncontrolled access.
  - Not established by the source: the cost of controlled access when the oracle block is a compiled circuit on hardware (each controlled block adds gates), or any lower bound for uncontrolled phase access.
- [I] Repository claim: "the corrected n = 3 linear code is a decisive negative control" (literature/notes/topics/open_gororoba_handoff.md, hidden oracle row).
  - Source: Introduction, linear f(x) = r.x: one quantum query, Theta(n) classical queries.
  - Model map: the n = 3 rung of Design C is the linear character x_1, the Bernstein-Vazirani instance; H_3 is the degree-at-most-1 code RM(1, 3) (note elkies-2013-m256).
  - Label: known theorem reproduced.
  - Not established by the source: any statement about higher rungs.
- [I] No repository claim: The classical bound in Theorem 9 is Theta(2^(N/4)) in the number of input bits N = 2n, not Omega(2^(N/2)). The introduction of arXiv 1103.3017 quotes the bent-function classical cost as Omega(sqrt(2^n)) with n the number of input bits; the two statements differ by a factor of 2 in the exponent (2^(N/4) against 2^(N/2)). A classical bound for an associator hidden shift needs its own derivation, since the Maiorana-McFarland argument uses a random permutation pi and the family H_n is explicit.
