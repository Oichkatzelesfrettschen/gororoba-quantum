## Main claims and evidence

- [P] A superconducting flux qubit under engineered, non-Gaussian dephasing noise reconstructs both the power spectral density and the bispectrum using a single measurement setup built on a statistically motivated maximum-likelihood estimator (introduction).
- [P] The Gaussian approximation breaks down when a qubit couples strongly to discrete noise sources; the bispectrum is the leading higher-order signature.
- [P] Quantum noise spectroscopy uses open-loop control modulation as a filter function that shapes the sensor's frequency response.

## Limits

- [P/I] The method controls the qubit's filter function with dynamical-decoupling-style sequences and probes an engineered noise source; it is not an analysis of a free-running shot record from a cloud job.
- [P/I] No mains or pulse-tube line detection.
- [P/I] A shot-record periodogram needs no filter function but also cannot separate noise coupling channels, which this method can.
