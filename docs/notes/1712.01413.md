## Main claims and evidence

- [P] The input is a partial network T, an arbitrary complex n x m matrix between annihilation operators that need not respect bosonic commutation relations; the method builds a full transformation S_total containing T as its upper-left block, with ancilla modes that supply the quantum optical description of loss and gain.
- [P] A singular value decomposition T = U D W splits the network into two unitaries on the nominal modes, implementable with phase shifters and beam splitters by Reck or Clements, and a diagonal modulation D in which each singular value couples one nominal mode to a vacuum ancilla.
- [P] A single lossy channel T = sigma, 0 <= sigma < 1, is a lossless beam splitter with transmission cos phi = sigma onto a vacuum ancilla. A singular value below 1 entails a beam splitter and one above 1 a parametric amplifier.
- [P] Ancilla count: a non-square n x m transformation adds (m - n) output ancilla modes when m > n, or (n - m) input ancilla modes when n > m, plus one full ancilla mode for each singular value of T different from 1.
- [P] Applications include Naimark extensions of POVMs, where rank-one elements E_i = |phi_i><phi_i| on nonorthogonal vectors are realized as a projective measurement in an enlarged space, and the design of probabilistic optical gates.
