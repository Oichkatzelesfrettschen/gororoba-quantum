## Main claims and evidence

- [P] Interleaving repetitions of a target gate inside a randomized benchmarking sequence separates unitary from non-unitary gate error: the benchmarking fidelity decays quadratically in the number of interleaved gates for unitary error and linearly for non-unitary error.
- [P] On the reported superconducting qubits the single-qubit gates reach 99.95% benchmarked fidelity and are limited by a drive-activated decoherence source rather than by unitary error.
- [P] Process tomography and gate set tomography carry more information than error verification needs, and standard randomized benchmarking carries too little.
