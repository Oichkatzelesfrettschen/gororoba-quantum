## Results that constrain the repository design

[P] State tomography assumes known measurement effects spanning operator
space. Process tomography also assumes known input preparations spanning
operator space. Section 2.2 writes the observation matrix as `P=A*G*B`;
`A` needs full column rank and `B` full row rank. Equations (27)-(28)
reconstruct the process using inverses or pseudoinverses. Counting settings
without checking these ranks does not establish informational completeness.

[P] GST removes the assumed known preparation/measurement reference frame
by estimating operations jointly. Equation (15), p. 8, transforms
`rho -> M*rho`, `E -> E*M^-1`, `G -> M*G*M^-1`, for invertible `M`, while
preserving observable circuit probabilities. Sections 3.1-3.2 reconstruct a
self-consistent gate set up to this common gauge. The additional null-operation
circuits determine the Gram matrix `A*B`, equations (38)-(40), p. 13.
Calibration-free characterization therefore retains an observational
nonidentifiability; it does not independently locate every error in SPAM or a gate.

[P] Section 6.1 compares fitted circuit probabilities with a saturated model
using likelihood-ratio goodness of fit. The interpretation assumes successful
likelihood optimization and the declared gate-set model. Context dependence,
drift, leakage and persistent environments can violate that model. A large
significance statistic measures evidence of model failure; it does not by
itself quantify the physical magnitude or identify a unique mechanism.

[P] Section 6.3 explicitly describes its error-bar methods as useful but
insufficiently developed for a standalone rigorous claim. Its discussion
motivates uncertainty reporting; it does not supply an automatic finite-sample
coverage certificate for a new repository fit.

## Repository use and qualification gates

[I] The [instrument-GST source](2103.03008.md) specifies the extra circuits
for continuing measurement. This source supplies the preparation/measurement
rank, null-reference and common-gauge obligations needed before calling a
future folded-QPE characterization complete. A terminal outcome distribution
or confusion matrix identifies fewer degrees of freedom than an instrument.

[I] Compare three designs against the same requested output: calibrated
process tomography, self-consistent GST/QILGST, and a targeted endpoint
experiment. Calibrated tomography spends fewer resources on the reference
frame but carries calibration uncertainty. GST estimates the reference
operations jointly and requires additional circuits and gauge interpretation.
A targeted contrast can resolve a declared decision without estimating every
channel entry. [Optimal experiment design](quant-ph-0411093.md) and
[selected-observable shadows](2002.08953.md) address different reductions.

Before a tomography case is admitted, retain the subsystem and outcome
alphabet, fiducial design matrices and singular values, SPAM assumptions,
CP/TP and leakage model, common gauge convention, finite-shot uncertainty
method, and independent predictive checks. Archive the full joint classical
record, including mid-circuit outcomes. Test simulated rank failure, gauge
transformations, preparation/readout mismatch and model violation locally.
The resulting checks qualify a proposed model and estimator; fresh physical
measurements remain necessary to characterize the actual device.
