## Main claims

[P] The sign function omega of every Cayley-Dickson doubling product satisfies two periodicity laws read off a binary "twist tree", which let omega(p,q) for large indices reduce to smaller ones.

- [P] Setup (Sec. 2 and 3): Cayley-Dickson algebras are twisted group algebras on (N_0, xor) with e_p e_q = omega(p,q) e_{p xor q}. The "shuffle basis" is e_0 = 1, e_{2k} = (e_k, 0), e_{2k+1} = (0, e_k) (Eq. 2.2 to 2.4); conjugation is (a,b)* = (a*, -b).
- [P] Table 1 lists eight doubling products: P0 (ca - b*d, da* + bc), P1 (ca - db*, a*d + cb), P2 (ac - b*d, da* + bc), P3 (ac - db*, a*d + cb), and the transposes P0T (ca - bd*, ad + c*b), P1T (ca - d*b, da + bc*), P2T (ac - bd*, ad + c*b), P3T (ac - d*b, da + bc*). Only P3 and P3T appear in the literature. For basis vectors e_p e_q = e_r in P_k iff e_q e_p = e_r in P_k^T; the relation holds on basis vectors only.
- [P] Twist trees (Sec. 4 and 5): the bits of p and q are shuffled into doublets, and each doublet selects a left or right branch; the sign at the terminal node is omega(p,q). The nodes are C, T, L, D, I; the interior trees I0 to I3 differ by product (Figure 4), and the other nodes are common to P0 through P3 (Figure 3).
- [P] Theorem 1 (stated as well known): omega(p,0) = omega(0,p) = 1; omega(p,p) = -1 for p > 0; omega(p,q) = -omega(q,p) for 0 != p != q != 0, for all eight products.
- [P] Theorem 2 (first periodicity): if 2^(N-1) <= p < 2^N <= q < 2^(N+1) and k >= 0, then omega(p,q) = omega(p, q + k 2^N).
- [P] Theorem 3 (second periodicity): if 2^(N-1) <= p, q < 2^N and k >= 0, then omega(p,q) = omega(p + k 2^N, q + k 2^N).
- [P] Theorem 4: if 2^(N-1) <= p < 2^N <= q, then omega(p,q) = omega(p, 2^N + (q mod 2^N)); example omega(5,481) = omega(5,9).
- [P] Theorem 5: if p and q share the top bit position M and 2^(N-1) <= p xor q < 2^N, then N < M and omega(p,q) = omega(2^N + (p mod 2^N), 2^N + (q mod 2^N)); example omega(483,481) = omega(7,5).
- [P] The proofs navigate the trees and are stated for P0 through P3; "a variation is valid for the transposes". The stated purpose (Sec. 6) is cheaper evaluation of omega at large indices, for example in A_10.

## Mapping to this repository

Convention map.

- [I] The repository's doubling, (ac - conj(d) b, d a + b conj(c)) in the gororoba_quantum/cd_core.py module docstring, is Bales's P3T. The numbering differs: in the shuffle basis bit 0 of the index selects the last doubling, while in cd_core.cd_sign bit n-1 does (the first loop iteration compares against dim/2). Measured: with rev_n the n-bit reversal, cd_sign(2^n, rev_n(p), rev_n(q)) equals the sign recursion of P3T in the shuffle basis for every p, q, n = 3 to 6, 0 mismatches, while the unreversed comparison has 24, 108, 468, and 1956 mismatches. The shuffle basis is not stable under the inclusion A_n in A_{n+1} (it sends e_k to e_{2k}), so a Bales index is meaningful only with its width n fixed. Under this map Bales's top set bit of an index is the lowest set bit of the cd_core index, and bitlen statements in cd_core terms become 2-adic valuation statements in Bales terms. The transposition omega_P3T(p,q) = omega_P3(q,p) holds on basis vectors (Sec. 2 and the Table 1 relation), so the P3 tree of Figure 3 and Figure 4 (I3) serves the repository through argument swap.
- [I] Table 1 as printed has a defect that bounds what the closed forms transfer. The P1, P2, P1T, and P2T doubling formulas, implemented as nested pairs exactly as displayed, give an 8-dimensional algebra that fails the norm identity and alternativity: for P2 with the repository's top-bit-last index, x = e_1 + e_4 and y = e_2 + e_7 give |xy|^2 = 8 against |x|^2 |y|^2 = 4, and A(e_1,e_4,e_2) + A(e_4,e_1,e_2) = 2 e_7, where an alternative algebra has an alternating associator. P0, P3, P0T, and P3T pass both tests. Alternativity is an isomorphism invariant, so the printed P2 is not isomorphic to the octonions at dimension 8, contradicting the statement in Sec. 1 of note 1602.02317 that all eight algebras are isomorphic. The cause (a misprint in both papers or a difference in the unread reference [4]) is not determined. No relabeling of the index by an element of GL(n,2) with a diagonal sign gauge maps the P1 or P2 tables onto cd_sign for n = 3 and n = 4, while every GL(3,2) relabeling works for P0, P3, P0T, and P3T at n = 3.

- [I] Claim (DESIGN_NOTES, "Phase degree along the ladder"): the sign function f_m(x) = [cd_sign(dim,m,x) = -1] has algebraic degree log2(dim) - 1 for every m != 0. Source: none states a degree; Theorem 4 constrains which bits of x enter the sign. Convention map: the lowest set bit t of the cd_core index m is the top set bit of rev_n(m), and the product is P3T. This is Theorem 4 read through the bit reversal, and it shows that the low t bits of x enter f_m only through the indicator [x mod 2^t != 0], which supplies the OR-shaped terms of the sign rows. Theorem 4 bounds the support, not the degree. The formula that would give the degree is the doubling recursion itself, which is Bales's Table 1 product with Eq. 2.2 to 2.4 and is the cochain recursion of note math-9802116 (Corollary 4.3): the induction there closes the claim for all n. Label: candidate new result.
