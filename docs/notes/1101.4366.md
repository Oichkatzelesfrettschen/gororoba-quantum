## Main claims and evidence

- [P] Direct state tomography needs measurements and computation that grow exponentially with system size.
- [P] For states well approximated by matrix product states, two one-dimensional schemes need a linear number of experimental operations and polynomial classical post-processing, and the reconstruction's accuracy is certified without prior assumptions.

## Mapping to this repository

- [I] Structure-exploiting tomography reaches large systems only for structured states; the repository's coherence designs instead target one selected density-matrix element, which needs four Pauli settings for a two-qubit pair whatever the rest of the register holds.
