## Main claims and evidence

- [P] A device produces i.i.d. states rho that should lie in a subspace V with projector P; the figure of merit is F(P, rho) = Tr(P rho), and verification is the hypothesis test "good" F >= 1 - tau epsilon against "bad" F <= 1 - epsilon.
- [P] Each round draws a two-outcome POVM {E_l, I - E_l} with probability p_l, where every state in V passes with certainty; the verification operator Omega = sum_l p_l E_l has the spectral form P + sum_j lambda_j |psi_j><psi_j| on the complement (Fact 1), with gaps Delta_min = 1 - lambda_(d_V + 1) and Delta_max = 1 - lambda_d.
- [P] Lemma 1: 1 - Delta_max epsilon_rho <= Tr(Omega rho) <= 1 - Delta_min epsilon_rho for the infidelity epsilon_rho, so the spectral gaps convert a pass rate into a subspace fidelity.
- [P] Theorem 1: when tau Delta_max < Delta_min, that is r = Delta_min / (tau Delta_max) > 1, the test needs N = ln(1/delta) / D[p0 || 1 - epsilon~] rounds, from Chernoff-Hoeffding bounds on Bernoulli pass counts, and scales as O(1/epsilon) to first order (Eq. 8). Proposition 1 turns the pass frequency into an infidelity interval with approximate confidence 1 - delta.
- [P] Stabilizer and QLDPC verification operators use O(n - k) local settings, with sample complexity O(n - k) and O((n - k)^2) respectively; combining subspace verification with direct fidelity estimation verifies logical magic states.
