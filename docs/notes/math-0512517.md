## Main claims

[P] The squared singular values of left multiplication by a doubly pure element form a spectrum whose zero marks zero divisors, and the pairs (a, lambda ee0) built from that spectrum are zero divisors one dimension up.

- [P] Notation (Section 1). ee0 = (0, e0) is the "symplectic unit" of A_n; for a = (a_1, a_2), ae = (-a_2, a_1) = a ee0. A pure element has real part zero; a doubly pure element is pure and orthogonal to ee0, so the doubly pure elements form R^(2^n - 2). Corollary 1.2: for doubly pure a != 0, span{e0, ae, a, ee0} is a copy H_a of the quaternions.
- [P] Section 2. Theorem 2.2: L_a^2 = R_a^2 for pure a. Theorem 2.3: for pure a, b in A_n, L_(a,b)^2 = [[A, -S], [S, A]] with A = L_a^2 + R_b^2 and S = R_b L_a - L_a R_b, so L_(a,b)^2 (x,y) = (A x - S y, A y + S x). Corollary 2.4: L^2 is unchanged under (a,b) -> (ra - sb, sa + rb) for r^2 + s^2 = 1 (an O(2)-action), and L^2_(a,-b) = L^2_(b,a). Theorem 2.6: if L_a or R_b is invertible and -1 is not an eigenvalue of (A^(-1) S)^2, then L_(a,b) is invertible (Schur complement, det L^2 = det A det(A + S A^(-1) S)).
- [P] Section 3. For doubly pure a with |a| = 1, V_lambda = {x in H_a^perp : a(ax) = -lambda^2 x}; Theorem 3.1: dim V_lambda is a multiple of 4. Spec(a) is the set of 2^(n-2) - 1 eigenvalues (each of multiplicity a multiple of 4) of -L_a^2 on H_a^perp; Spec(a) = {1} for a in A_3, and L_a is singular exactly when 0 is in Spec(a). Worked example (p. 14-15): a = (e1, e2) in A_4, with |a| = sqrt 2, satisfies (e1,e2)(-e4,e7) = (0,0), (e1,e2)(e2,e1) = (2 e1 e2, 0), L^2_(e1,e2)(e2,e1) = -2 (e2,e1), and L^2_(e1,e2)(e7,-e4) = -4 (e7,-e4), so Spec((e1,e2)) = {0, 1, 2}.
- [P] Remarks after the example: for alternative pure orthogonal a, b of equal norm, 1 is in Spec((a,b)); if also (a,b)(x,y) = 0 for some nonzero (x,y), then 2 is in Spec((a,b)), realized by (y,x), so {0,1,2} is inside Spec. The author reads this as a "mirror symmetry" between the zero and the 2 eigenvectors.
- [P] Theorem 3.2: a nonzero pure a is normed (|ax| = |a||x| for all x) exactly when it is alternative. Proposition 3.3: for x in V_lambda, |ax| = lambda |a||x|. Theorem 3.5: 1 is in Spec(a) for every nonzero doubly pure a. Corollary 3.6: dim Ker(a^2 I - L_a^2) >= 8.
- [P] Section 4. Lemma 4.1: every zero divisor is doubly pure. Lemma 4.2: (a_1,a_2) is a zero divisor exactly when (a_2,a_1) is, with a x = 0 exactly when the swapped pair multiplies to zero. Proposition 4.3: for doubly pure a and b in H_a^perp with |a| = |b|, (a,b) is a zero divisor of A_(n+1); (a, ae) and (a, -ae) are zero divisors. Theorem 4.4: for doubly pure a of norm 1 and 0 != lambda in Spec(a), (a, +-lambda ee0) are zero divisors of A_(n+1). Corollary 4.5: every nonzero pure unit alpha of A_n (n >= 3) has a unit beta orthogonal to it with (alpha, beta) a zero divisor of A_(n+1). Remark: unlike A_4, the halves of a zero divisor in A_5 need not have equal norm; example (a, sqrt 2 e8) with a = (e1, e2)/sqrt 2.
- [P] Section 5. A Stiefel element is (a,b) in pure A_n x pure A_n with |a| = |b| != 0 and a orthogonal to b; the unit ones form the real Stiefel manifold V_(2^n - 1, 2). Theorem 5.2: (a,b) is a Stiefel element exactly when (alpha, alpha-hat) is a non-trivial element of A_(n+2), where alpha-hat = (b,a). Theorem 5.3: the non-trivial elements with unit entries form the complex Stiefel manifold W_(m,2), m = 2^(n-1) - 1. The zero divisors of A_4 of unit norm are V_(7,2) (from [M1]); for n >= 5 the zero divisors are related to, but not equal to, the Stiefel set. Open question (p. 26): is every Stiefel element of A_(n+1) a zero divisor? Partial answer: those of the types in Sections 4 and 5 are.

In A_5 all 32 have nullity exactly 4 (rank 28 modulo 2^61 - 1 and four exact rational kernel vectors); in A_6 all 32 have nullity 0 (full rank of the integer matrix D L_v modulo 2^61 - 1, so det L_v != 0). The disjoint-support A_6 element of seed 0, an integer vector with entries in [-3, 3] retained in the evidence, is an explicit Stiefel element that is not a zero divisor, so the answer to the open question is negative at A_6. Moreno's own zero divisors of Proposition 4.3, (e1 + e2, e3 + e4) and (e1 + e2, (e1 + e2) ee0), are A_6 Stiefel elements with nullity 28 and serve as the positive control. Theorem (generic invertibility at A_6): on the normalized Stiefel family V = {(a, b) in (Im A_5)^2 : |a| = |b| = 1, a orthogonal to b} = V_2(R^31), a connected real-analytic manifold of dimension 59, the left-multiplication determinant F(a, b) = det L_(a,b) is a polynomial in the coordinates. The integer witness has |a|^2 = |b|^2 = 62 and a.b = 0, so its normalization lies in V, and det L_v is nonzero there: its residues are 810824905836647058 modulo 2^61 - 1 and 486680426 modulo 10^9 + 7, both retained in the evidence and both equal to an independent external computation. A real-analytic function that is not identically zero on a connected real-analytic manifold vanishes on a closed set with empty interior and measure zero, so the invertible A_6 Stiefel elements form an open, dense, full-measure subset of V, and the zero-divisor Stiefel elements a closed measure-zero semialgebraic subset of dimension at most 58. This does not determine that subset's exact dimension, components or geometry, and does not settle the universal A_5 question. Label: new exact measurement; the repository's literature notes contain no A_6 Stiefel statement, and no wider literature comparison has been made. Not established here: that every A_5 Stiefel element is a zero divisor, which the 32 exact points support but do not prove.

## Gaps and cautions

- [P] The paper states that its description of zero divisors in A_n for n >= 5 is incomplete and "extremely difficult"; the Stiefel manifold relation is by inclusion of constructed families, not a classification.
- [I] The extraction lost conjugation bars, so the proofs of Lemma 1.1 and Lemma 2.1 were not re-derived; Theorem 2.3 was checked on the case a = b = e1 only.
- [I] The comparison with the 2007 joint preprint of Moreno and Gonzalez-Flores cited in note 0905.2987 was not made; theorem numbers here belong to this arXiv version only.
