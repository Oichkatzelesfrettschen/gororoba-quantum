## Case A: sedenion zero-divisor dark/bright on 18 modes, 1 photon

- Algebra: a = e1 + e10, corpus pair (e1 + e10)(e4 - e15) = 0 (cd_core), bright
  control (e4 + e15).
- Map: V = L_a restricted to columns {e4, e15}, singular values (2, 0),
  scaled by 1/2; unitary dilation U = [[V, sqrt(I - V V^T)], [sqrt(I - V^T V), -V^T]],
  18 x 18 (16 algebra modes + 2 dilation modes). A BS on inputs 0, 1 and a
  pi phase on input 1 prepare (e4 - e15)/sqrt2; no phase gives (e4 + e15)/sqrt2.
- Ideal: dark input exits the 2 dilation modes with P = 1; bright input stays
  in the 16 algebra modes with P = 1 (SLOS, verified).
- Platforms: 18 modes <= 24 on qpu:belenos and sim:belenos; 1 photon (Belenos
  min_photon_count 1); sim:slos needs >= 2 photons, so not there.
- Hardware question: the dark-floor and bright-ceiling contrast under the chip's
  loss, dark counts and transpilation fidelity of an 18-mode unitary.

## Case B: octonion associator-sign interferometer on 16 modes, 1 photon

- Arms: A = L_{e_i} L_{e_j} on modes 0..7, B = L_{e_i e_j} on modes 8..15; split
  and recombine each pair (k, 8 + k) with a 50:50 splitter: M = H (A + B) H.
- Ideal for (i, j) = (1, 2): photon from input k exits the minus ports (8..15)
  with P = 1 for k = 4..7, where the associator (e1, e2, e_k) is nonzero, and
  P = 0 for k = 0..3, the quaternion subalgebra (SLOS, verified). cd_core
  classifies octonion imaginary triples as 42 associating, 168 non-associating.
- Name: associator-sign interference witness (AGENTS.md algebra rules). A single
  photon through linear optics is classical-wave interference; the case claims
  implementability and measured contrast, not nonclassicality.
- Literature: compare docs/notes/1602.01624.md (single-photon test of
  hypercomplex quantum theories) and its dispute (1604.04950, 1607.01648)
  before any priority statement.

## Box-kite photonic family (design facts, 2026-10-17, local only)

- Rows come from docs/evidence/box_kite_census/census.json (package-witnessed),
  with the case-digest schema of scripts/box_kite_cases.py and parallel.py for
  every row loop.
- Uniform dilation scale: V = (L_x restricted to span{e_L', e_U'}) / sqrt2 for
  normalized x gives P(algebra modes) = ||x y||^2 / 2 = census p_selector_zero
  on all 1176 rows (840 within-kite, 168 cross-kite, 168 non-kite), exact in
  Fractions; every ||V||_op <= 1. Per-row max-singular-value scaling (the
  first case A prototype) is wrong on strut rows.
- Reduced encoding: each row is a 4-mode, 1-photon circuit (2 XOR labels + 2
  dilation modes). CORRECTED (PR #226): within-kite rows use 12 sign blocks
  M (24 (M, t) configurations), non-kite rows 4 more; the census reaches 14
  of the 16 +-1 matrices (the two sets overlap), and two strut-type blocks
  need cd_core witness pairs outside the Design B rows. The earlier "40 x 21
  = 16 blocks" line merged sources and was wrong.
- D = 32 and 64: 5040 and 52080 signed zero products, equal to the
  annihilator nullity sums and to open_gororoba EXACT_ALTERNATOR_COUNTS; every
  two-label product maps to one of the 32 (M, t) circuits
  (docs/evidence/box_kite_census/two_blade_blocks.json).
- Preregistered layers: census ideal, local NoiseModel from catalogue perfs,
  sim:belenos, qpu:belenos. Contrast metric: the Tuna-17 endpoint contrast
  (0.0415 +- 0.0032 vs ideal 1 for a = e1 + e10). Start one block per job;
  packing adds inter-block crosstalk as a separate variable.

## Written case S3: belenos_mesh/job-00 on sim:belenos (sims approved)

What it measures: one iterated job of the Belenos architecture circuit with
16 phase settings (compiled-bright replay, hot and cold identity, hot and
cold bright, compiled and cold dark, cold bright at mode 0, cold edge and
strut fringes at phi = 0, pi/2, pi, 3 pi/2), 1500 samples each.

accepts an architecture-form circuit without re-transpiling (each
iteration's computed_circuit must carry the sent phases to 1e-9) and whether
its sim of those meshes matches the local mesh model's ideal per setting.
Platform sim:belenos, 24000 samples, max_shots 48000, expected about 200 s
(16 iterations at about 11 s if the server still compiles), 1 credit
(per-job price; sim shots cost 0), ceiling 1.00. Plan 2026-10-17T232626Z
passed every check including the live-architecture comparison.

## Written case M1: belenos_mesh/job-00 on qpu:belenos (awaiting approval)

## S3 outcome (job 1d7160c1, 1.00 credit)

Every one of the 16 settings reproduced its local mesh-model ideal on
sim:belenos (TVD 0.0002 to 0.038 at 1500 samples), but the server
re-transpiled every iteration: all 574 phases changed, only the occupied
column survived, every returned mesh drives about 1800 rad of heater phase and
spreads the photon over modes 16 to 23. The parameterized architecture form
does not reach the chip. M1 as written is void.

## Written case C1: belenos_mesh/job-03..06 on qpu:belenos (awaiting approval)

Supersedes M1 as the first QPU step: one 16-setting job cannot identify
static offsets (held-out TVD 3 to 12 floors), while 64 random-target settings
can (0.1 rad recovered to correlation 0.89 locally). Four iterated jobs of 16
seeded uniform-random meshes, inputs rotating over the 12 connected modes,
1500 samples each, back to back in one calibration session (each plan checks
the couplers). Analysis frozen at the pushed commit: class scans with the
pooled-deviance and TVD-floor test per job, `--static` over the four runs
(one fold per run), source models for the misroute.
Gate: the plan's live-architecture check passes. The HOM >= 90 % gate is
withdrawn: the approved replay R1 (job 7af74302, 2026-10-18T02:54Z) ran Q1's
identical mesh 29dc6ef8 at HOM 57.6 % and read raw in-block 0.504 (Wilson
0.494 to 0.514) against Q1's 0.470 (0.460 to 0.480) at HOM 92.6 %, the same
leak onto modes 17 to 19 with small drift (mode 16 483 -> 261), so the HOM
figure does not index this one-photon route's leakage. (The dark-corrected
0.520 / 0.505 quoted in the submit approvals rest on the receipt dark model,
which C1 job-03 refutes: modes 0 and 1 read zero clicks where it predicts
about 150 and 40.) Approved by the user 2026-10-17: "C1 approved to run on the
real quantum hardware finally as well as an exact resubmission of the first
QPU job for before/after on that as well but C1 is primary!"
Outcomes and what each triggers:
- static declared: session-keyed offsets; compile candidate seeds on
  sim:belenos, predict each under the offsets, run 84/84 with the best;
- a class fits (dephasing, gain, crosstalk, misroute): seed ensembles per
  configuration sized to the fitted magnitude; a misroute class reroutes
  inputs;
- ideal: Q1 was a calibration episode; run 84/84 (job-02) directly;
- no class fits: report the residual; ensembles with split-half selection
  (literature rule) for 84/84.
Cost 4 x 1.024 = 4.10 credits, ceiling 4.19. Optional exact replay of
single/job-04 (1.01) for an identical-mesh before/after test.
