- The full graph automorphism group of S_n equals the signed-permutation
  boundary group at n = 2, 4, 8, 16 (nauty orders 4, 24, 336, 672).
- The n = 4 action is abstractly SL(2,3) but not the Hurwitz-unit left
  multiplication: that action is quaternionic (FS -1), this one is complex
  (FS 0). The note's "binary tetrahedral group of the 24 Hurwitz units" names
  the abstract group only.

## The mechanism: the boundary is a skew conference matrix

The arc matrix W_n[a XOR b, a] = cd_sign(n, a, b), b >= 1, is right
multiplication by s = e_1 + ... + e_{n-1}, and B_n is its signed support, so
the boundary group is exactly the signed permutations commuting with W_n [T].
W_n is skew with W_n^T W_n = (n-1) I at n = 2..128, so I + W_n is a skew
Hadamard matrix of Sylvester order in every tested dimension.

- n = 4, 8: W_n is signed-permutation equivalent to the Paley skew conference
  matrix of q = 3, 7 (24 and 336 equivalences, equal to each automorphism
  group). The lattice group is the Paley matrix's automorphism group, which
  Hall's theorem places over PSL(2,q) acting by Moebius maps [P, to source].
  The octonion case is the quadratic-residue difference set {1, 2, 4} mod 7.
- The e_0 stabilizer (order 21 at n = 8, 16) equals, as a set, the
  index permutations that are XOR-linear and preserve cd_sign: the lattice
  group meets the algebra's automorphisms only there (6, 42, 42 elements of
  G_4, G_8, G_16 have XOR-linear index maps).
- n = 16: no Paley matrix exists (15 is no prime power); the group grows
  by an outer involution class to 2.PGL(2,7). The 120 index pairs split into
  orbits 8 (doubling pairs) + 56 (all 42 assessors plus 14) + 56; B_16 splits
  32 + 224 + 224.

## Falsified prediction

Predicted before the run: if the e_0 stabilizer stays 21 and the action stays
transitive, |G_32| = 64 x 21 = 1344. Observed: |G_32| = 672, stabilizer 21,
two orbits of 32 signed units ({0, 17..31} and {1..16}). The nauty count of
the signed centralizer of W_n, calibrated at n = 4, 8, 16, 32 against the
backtracker, stays 672 at n = 64 and 128 with n/16 orbits of 32. W_32 is not
Paley-equivalent [T]: x -> x + 1 preserves the q = 31 Paley matrix, an
automorphism of order 31, and 31 does not divide 672.

## Open conjectures with falsifiers

1. W_n^T W_n = (n-1) I for every Cayley-Dickson n (right multiplication by the
   imaginary sum is a similarity). [E] to n = 128. Falsifier: a failing
   n >= 256. Lead: Kivunge (Mile High 2013 abstract) reports Cayley-Dickson
   sign matrices are Hadamard; prove the skew form by induction on the
   cd_sign doubling recursion.
2. |G_n| = 672 for all n >= 16, acting as G_16 on each block of 32 signed
   units. [E] to n = 128. Falsifier: a larger order at n = 256, or a block
   action not permutation-isomorphic to G_16 on 32 points.
3. Settled: the n = 16 commutant has an integer basis 1, J, K, JK with
   J^2 = -7, K^2 = -1, JK = -KJ [E], so it is (-7, -1)_Q, ramified at
   {7, infinity} [T]: -7 is a square in Q_2, and -1 is a non-residue mod 7.
   K = +-R_e8, right multiplication by the doubling unit.
4. A boundary rule built from the four-index assessor relation is the
   sedenion analogue of the Paley rule (still open from the note).
