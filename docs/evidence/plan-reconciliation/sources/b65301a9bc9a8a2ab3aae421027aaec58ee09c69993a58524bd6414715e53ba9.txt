## What changed

- `qpe_diagnostics`: variant `window_delay_long` (control idles `2 * window_delay_dt`, same barriers),
  in `N21_ORBIT_SWEEP_VARIANTS`. `N21_ORBIT_VARIANTS` itself is unchanged. New builder
  `n21_spectator_ramsey(kind, quadrature, measure_dt, init_herald)` and its law `n21_spectator_law`.
  Logical qubit 2 starts in |+>. A barrier opens the bracket, then the control is measured into
  clbit 0 (or, for reset_only, idles `measure_dt`), then reset, then a barrier closes the bracket.
  Qubit 2 is read in X (h) or Y (sdg, h) into clbit 1. Ideal laws over control + 2*q2: X [1,0,0,0],
  Y [1/2,0,1/2,0]. With a herald, the members carry the same herald register and lift. `_verify`
  covers the plain and heralded spectators; their reset_only twins skip the window-bracket check,
  since no measurement opens a window there.
- `diagnostic_experiments.n21_orbit_rca_group(..., window_sweep=False)`: `window_sweep` adds the long
  pair and members `n21_spectator_{measured,reset_only}_{x,y}`, all dynamic, giving one group and one
  job. `family_contracts` adds a directional endpoint for `window_delay_long` and precision-only
  endpoints `n21_spectator_*_one` on the qubit-2 bit. All endpoints share `alpha / (variants +
  spectators)`. `record_groups` reads `window_sweep` with a False default.
- Planner: `family_candidates` builds with `window_sweep=True` and records `"window_sweep": true` in
  the family configuration. `qpu_planning.orbit_sites` restricts `window_controls` to orbit arms,
  because a reset_only arm resets before any measurement and would raise there. `_control_windows`
  preserves the sweep flag on resize. Contract fixtures were updated: 14 arms, the long delay
  equals 2x, the spectator readout/reset/idle structure is checked, the twins take the flag, and the
  herald summary has 14*4 keys.
- `qpu_cases`: a case-text paragraph describes the new arms, emitted only when the record's family
  configuration carries `window_sweep` (n21-orbit-feedback and older n21-orbit-rca cases unchanged).
- Analyzer (`scripts/n21_orbit_rca.py`):
  - `ORBIT_VARIANTS` gains `window_delay_long`, and `CONTRACTS` has five entries, so
    `CONTRACT_ALPHA = 0.01`.
  - `is_orbit` filters `window_roles`, `measured_pairs` and `herald_counts`/`herald_report` (via
    `select`). `raw_pubs` keeps binding every PUB.
  - New `magnitude_decline`, which implements `window_delay_ramp`.
  - New `spectator_visibility`, `spectator_contract` (`spectator_window_dephasing`),
    `spectator_counts` and `spectator_margin`.
  - `between_arm_report` adds `spectator_herald` and `spectator_counts`.

## Decisions where the spec and code conflicted

1. **Configuration flag instead of an unconditional group.**
   - `record_groups` rebuilds retained records (live_run collect, local_member_cz_conformance
     core-289).
   - The new arms are behind `window_sweep`, absent = False, so retained eight-member records rebuild
     unchanged.
2. **Measure duration reuses `window_delay_dt`.** No new configuration key was added.
   `window_durations` already sets `window_delay_dt` to the routed control's calibrated measure
   duration (rounded to granularity). The case text states this.
3. **Herald margin direction.**
   - Both new contracts pass on a significant decrease, so subtracting the margin, as the spec says,
     would make a pass easier.
   - Instead, the margin is added against the pass: pass iff `upper + margin < 0`.
   - A planted check shows that a ramp which passes at margin 0 fails at a margin of 1.01 x |upper|.
4. **Spectator herald.**
   - `HERALD_SENSITIVITY` is derived for the orbit laws, so the orbit herald admission reads orbit
     members only, as the spec asks.
   - The spectator members get their own `herald_report` (`spectator_herald`).
   - The spectator margin is 2 x the qubit-2 bit's simultaneous spread upper limit. An excitation
     maps |+> to |->, which scales R by 1 - 2 eps.
   - A refused or unevaluable spectator herald refuses only `spectator_window_dephasing`.
5. **`is_orbit` = "not a spectator member".** An earlier version listed the orbit variants and broke
   the n21-orbit-feedback replay core-443 (members `n21_orbit_feedback`/`no_feedback`). The version
   that names the spectators fixed it.
6. **Alpha moves to 0.05/5 = 0.01.**
   - MDE is now 0.01905 (was 0.01786) and B is 0.001361 (was 0.001276) at 27,648 shots; the 7B phase
     is 0.0095 rad.
   - Docstrings and QPU_OPTIMIZATION.md were updated.
   - N21_ORBIT_RCA.md's forecast table ("alpha 0.0167 each") is historical and was left as written.
