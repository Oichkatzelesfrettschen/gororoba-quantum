# boxkite-generator: box-kite case generator and program rewritten to the reduced remote budget

Owner session: boxkite-quantum-main. Branch: research/box-kite-case-generator
(origin cb8c5a5; main merged locally; opus agent rewriting now).

## Finding

The generator (cb8c5a5) emits family (a) exhaustively for remote QX: 848
circuits in 284 batches, and the program plans 44 Tuna-17 batches (132
jobs, 16384 shots, about 23 min execution, 3 h wall). Remote QX is an ideal
state-vector emulator, and `verify_circuit` already state-vector-checks
every emitted .cq, so a remote run adds only the platform compile path
(parser, bit order, gate set, angle grid). The owner (2026-10-17) fixed the
rule: remote backends run smoke sets and device questions; exhaustive ideal
emulation runs on Kaggle CPU.

## Reachability

`scripts/box_kite_cases.py --write/--check/--self-test` and the case
directories under results/quantum_inspire/cases/ that `qi_platform.py
submit` consumes; docs/notes/box_kites/experiment-program.md drives every
later submission.

## Design (agent brief, in priority order)

1. Run the three checks skipped at the last shutdown (-O --check, serial vs
   pooled, retention under -O).
2. Family (a) remote QX smoke set: one replica per gate pattern (full: edge
   dark, edge bright, strut, x_sign -1, y_sign -1, cross-kite, non-kite,
   negative fixture; reduced: edge dark and bright with local-Z SELECT,
   strut with Sdag-CNOT-S SELECT, cross control), about 10 circuits in at
   most 4 batches; the 1133 old files are replaced.
3. Kaggle sweep entry (see boxkite-kaggle-sweep.md).
4. Tuna-17 series, 10 batches (see tuna-boxkite-stages.md), tuna dialect,
   twin() for witness circuits only.
5. Gates core-420..core-427 (--check, --self-test, normal and -O), the
   toolchain record regenerated for the new cases (core-368).
6. Program rewrite: sections 1, 4(a)-(g), 5 budget, 6, 7.
7. If budget remains: (d1)-(d3), (e) smoke + sweep, Ry ladder R0-R9.

## Acceptance and falsifier

Every generated batch passes check_qi_platform_retention.py; --check is
byte-equal in normal, -O and GOROROBA_WORKERS=1; each smoke circuit
reproduces its census row by state vector. Orchestrator review of the diff,
then the QI/registry pr gates and ruff/mypy locally. Falsifier: a smoke
circuit whose state-vector marginal differs from census P, or a Tuna
circuit off the pi/36 grid or using an excluded qubit.
