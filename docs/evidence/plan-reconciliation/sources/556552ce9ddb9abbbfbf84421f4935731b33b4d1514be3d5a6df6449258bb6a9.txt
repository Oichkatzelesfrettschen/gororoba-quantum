# Work plans for the open items

One plan per open item, written by the session that owns it, in this
directory (docs/local is untracked and shared by every session on the build
host). A plan is complete when every section of TEMPLATE.md is filled from
the code, the issue and the retained evidence. Implementation starts after
every listed item has a complete plan, and then each session works its own
items in isolation, with at most two subagents (haiku, sonnet or opus, by an
explicit `model`) running at any one time.

## Shared files

Several items write the same files; the plan names each one it touches so
the second PR to land knows to reconcile:

- ci/gates.json: every item that adds a gate (names from the ranges above).
- docs/state/research_state.json and its rendered README, roadmap and
  RESEARCH_STATE sections: reconcile by taking main's version and rerunning
  `"$PYTHON" scripts/research_state.py --write`.
- live_run.py and experiments.py: a change also gets a dry run under
  results/live/ (AGENTS.md).

Before merging, run `"$PYTHON" ci/premerge_gates.py BRANCH` (PR #190) once it
is on main.
