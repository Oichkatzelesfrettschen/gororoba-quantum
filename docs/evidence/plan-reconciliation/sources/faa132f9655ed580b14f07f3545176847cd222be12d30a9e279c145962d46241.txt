## Decisions where the spec and code conflicted

1. **Immediate and idle spectators get a terminal control reset.** As written they are static circuits, and the planner refused the group: "one result group mixes static and dynamic circuits". A barrier and then a control reset after qubit 2's readout makes them dynamic, so the group stays one job. The ideal law is unchanged, and qubit 2 is read before the reset. Alternatives were a separate static group or requiring `--init-herald` (the herald already makes them dynamic).
2. **Direction of `window_overlap_loss`.** "contrast_floor machinery, herald_margin subtracted" tests reaching the reference, but the pass is "B < A". I used `magnitude_decline(unbracketed, nominal)` with the margin counting against the pass, the same resolution as decision 3 of the window-sweep report.
3. **Self-test (c) at 65536 shots contradicts itself.** At that depth and phase 0, idle 0.97 vs immediate 0.98 is about 8 sigma, so `spectator_idle_dephasing` would pass. The spectator truths are planted at 4096 shots, a plan tier, and phase pi/4. There 0.01 is below the minimum detectable difference (SE about 0.016) and 0.37 is far above it. The overlap truths use the 65536-shot depth.
4. **`N21_SPECTATOR_KINDS` was not extended in place.** That would have changed the window-sweep groups. A split-kinds tuple carries the new kinds.
5. **The unbracketed coupling gates nothing.** The magnitude removes the work phase, and a CZ in the window can legitimately change the coupling. A planted roles test shows that a missing unbracketed pair is not admissible, and a differing or unresolved one is admissible.
