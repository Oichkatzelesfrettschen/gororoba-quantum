# n21-orbit-rca: delay sweep and qubit-143 window Ramsey

Branch `n21/orbit-window-sweep` (worktree `~/worktrees/IBMQuantum/n21/orbit-window-sweep`).
Read first: root AGENTS.md (gates, voice, S101, parallel.py), results/live/N21_ORBIT_RCA.md
(section "Contract forecast on the pre-barrier run"), results/live/PATCH_WINDOW_FINDINGS.md.

## Goal

Add two arm sets to the `n21-orbit-rca` family, in the SAME `n21_orbit_rca` Group
(one layout, one dynamic job; static and dynamic circuits must never share a group):

1. **Delay sweep.** A second window_delay length. Today `window_delay` idles the
   control `window_delay_dt` (415 dt, one readout) after reset. Add variant
   `window_delay_long` idling `2 * window_delay_dt`, feedback and no_feedback
   members, same barriers. Discriminates a monotonic decoherence ramp (magnitude
   keeps falling) from a one-time post-reset step (flat beyond the first delay).
2. **Qubit-143 window Ramsey.** Four-qubit members on the same logical qubits as the
   orbit (control 0, work-for-1 1, work-for-4 2 = physical 143, work-for-16 3):
   logical qubit 2 in |+> (H), others |0>; barrier; control measured into a bit then
   reset (as the orbit window does), with a work-side idle equal to the orbit's
   window bracket; barrier; read qubit 2 in X or Y (Y: sdg then h). Reference:
   `reset_only` with the control's measurement replaced by a delay of the calibrated
   measure duration (see patch_characterization.measurement_window for the exact
   pattern and naming). Members: measured_x, measured_y, reset_only_x,
   reset_only_y. These are dynamic (mid-circuit measure/reset), so they belong in the
   dynamic job. Their ideal laws: X -> qubit-2 bit 0 with probability 1; Y -> 1/2.
   If init_herald is on, they carry the same herald register and lifting as the
   orbit members.

## Analyzer (scripts/n21_orbit_rca.py)

- Every function that iterates group members (window_roles, measured_pairs,
  raw_pubs carried check, admissibility, herald paths, summarize) must select the
  orbit members by name and skip the Ramsey members; ORBIT_VARIANTS gains
  `window_delay_long`.
- New preregistered contract `window_delay_ramp`: one-sided test that the
  window_delay_long magnitude lies below the window_delay magnitude (contrast_floor
  machinery or equivalent delta-method test, herald_margin subtracted as for the
  other magnitude contracts). Pass = monotonic ramp; fail = consistent with a step.
- New preregistered contract `spectator_window_dephasing`: from the four Ramsey
  members, visibility R = hypot(<X>, <Y>) measured vs reset_only; one-sided test that
  R_measured < R_reset_only (delta method on the binomial counts).
- CONTRACTS grows to five; CONTRACT_ALPHA = FAMILY_ALPHA / len(CONTRACTS) follows.
- Self-tests (extend self_check / self_test_herald pattern): plant (a) static
  detuning truth: magnitudes flat, ramp fails, spectator fails; (b) monotonic
  dephasing truth: ramp passes; (c) 143 readout-dephasing truth: spectator passes;
  (d) step truth: ramp fails while delay magnitude < nominal. Each must reach the
  expected verdict.
