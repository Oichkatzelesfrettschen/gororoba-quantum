  "Components" of the fiber (`purpose.md` deliverable) must include embedded primes, which `minAssChar` discards.
- Remedy: record K2's non-radicality and the 12-dimensional linear span of the reduced support in the decision record;

### R3 (medium). Method B as coded is the special fiber; the global t = 0 is correct, with one assumption left unstated

- Pivot test `templates/b_body.sing:18`: `reduce(quotient(sJ0,ideal(G[i])),sJ0)==0` is exactly J : g = J, g a
  nonzerodivisor on R/J globally, hence on A_m. Rees ideal `:24-25`: H = J + (g y_j - G_j y_q), `sat(H,g)`. Over R_g the
  ideal I is principal (g) and the kernel of R_g[y] -> R_g[It] is generated by y_j - (G_j/g) y_q; the Rees kernel is
  g-saturated because g is a nonzerodivisor on R/J and so on R[It] subset (R/J)[T]. So sat(H,g) is the Rees ideal.
- Localization: `:27-28` adds all source variables, i.e. the maximal ideal m of the origin. R[It]/mR[It] =
  sum I^d/mI^d, each summand killed by m, so it equals its localization at m: global = local, and no component of
  Rees(I) away from the origin enters. This holds only because the boundary point is the origin of the translated
  coordinates (true by construction of the inputs) and because I is generated by the same G locally and globally.
- Unstated: J is assumed to be the ideal of Y near 0 (radical, no extra component through 0). If J has an embedded or
  extra component through the origin, both A and B compute the fiber of (G) on Spec R/J, not on Y. `dims_xm.log`
  shows dim R/J = 4 globally for X-, consistent with the germ dimension, but radicality/primality of J at 0 was not
  checked in any file I found.
- Minor: `:33` prints h_d only to d = 5; the Hilbert numerator from `hilb(Fy,1)` is the complete datum, so this is
  harmless.
- Remedy: one cheap `radical(J)` / `minAssChar(J)` check per input, recorded beside F6.

### R5 (low). Method A and the helpers: no code defect found; two fragilities

- Method A degree 2 (`templates/a2_body.sing:7-11`): P2 is all i <= j products reduced mod std(J), Q = J + m*P2,
  NF by `reduce` against std(Q). NF is linear (Singular's default `redTail` gives full normal forms), so rank of the NFs
  = dim (J+I^2)/(J+mI^2) = dim I^2/mI^2 in A, exact because the quotient is killed by m.
- Degree 3 (`runs/s1/input.sing`, tail): cubic representatives from `kbase(std(K2),3)`; `leadexp` of a kbase monomial is
  its exponent, and each factor is reduced mod J as it is multiplied, so the product equals the monomial in G mod J.
  Spanning: each K2 relation r has r(G) in J + mI^2, so y_f r(G) lies in J + mI^3, and the standard monomials of K2
  span F(I)_3. Using only those 122 products in Q is valid: I^3 = (P3') + J locally by Nakayama, and the global quotient
  (J+P3')/(J+mP3') is supported at m, so it equals the local one. The G list of probe G, S1 and S2 is byte-identical
  (checked), so the y-indexing of `xm_nm_fiber.rel` matches S1's G (`k2cmp.log` confirms the K2 ideal).
