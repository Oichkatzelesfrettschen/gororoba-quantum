# Audit of the Kaggle pulls and the unretained local run directories

Scope: every kernel output under `docs/local/kaggle-pull/<slug>/` (index.txt lists 32 kernels, not 34) and the run
directories of the primary checkout's ignored `docs/local/`. Method: every log, summary and result file named below
was read; every pulled file was compared by sha256 against all tracked files and against the primary checkout's
`docs/local/` (size-filtered sha256 matching; scripts were scratch and are not retained). A second pass harvested every
rank record (`r_N` with per-block ranks, prime, d, N, header hash) from all tracked `docs/evidence` JSON/JSONL and from
the ignored `a5-failed-runs`, Azure, laptop and probe directories (495 records, 148 header-prime-degree-N groups)
and compared them: no group holds two different 4-block rank tuples except three deliberate fixtures (the W8 d = 3 N = 10
`keep0/1/3` partial-block runs in `A5/w8-engine-map/logs/` and the two review `selection-attacks` records with r 122
against 265, the "corrupted review-attack record" of `A5/forecasts/trends-2026-11-06.md:13`). Repo paths are relative to
`docs/evidence/a5-exceptional-fibers/` (abbreviated `A5/`) unless they start with `docs/` or `results/`.

Tally for the 32 kernels: 10 CARRIED, 0 CARRIED-DIFFERENT, 3 NEW-RESULT, 19 FAILED, 0 SMOKE, 0 UNDECIDED. Section 2 holds the rest.
No pulled number disagrees with a tracked number. Every comparison that found a counterpart agrees to the digit.

Standing facts that shape the classification:

- 18 of the 26 A5 kernel outputs are complete byte-identical copies of an earlier pull in the primary checkout's
  ignored tree: 10 in `docs/local/a5-failed-runs/distribute/out/<slug>/`, 7 in `docs/local/a5-failed-runs/kaggle-v7/out/<slug>/`
  and 1 in `docs/local/a5-iso-np-h3-analysis/`. The other 8 match nothing locally: `a5-e8-np-fiber-singular`,
  `a5-fiber-pack-b`, `a5-iso-nm-msolve`, `a5-iso-np-msolve`, `a5-w8-nm-fiber-singular`, `a5-w8-np-fiber-singular`,
  `a5-w8-np-msolve` and `a5-e8-np-msolve` (only its input equals `A5/working/inputs/e8_np.ms`). All eight FAILED
  except pack-b's Iso job, which is CARRIED. The pull therefore re-downloads outputs the operator already held locally; the only A5 results it holds that no
  tracked file carries are the two NEW-RESULT A5 rows below (both also present in the ignored tree). The ghost and
  null-epistemics outputs have no local copy elsewhere.
- A kernel whose `rc` is 124 hit the in-kernel `timeout`; `rc` -9 is the kernel OOM killer (peak RSS about
  31.35 million KiB of 32.87 million KiB). RSS values below are KiB figures converted to GiB (divide by 1,048,576).
- Ledger rows A5-080, A5-086, A5-092 and A5-098 (`A5/ledger.tsv:80,86,92,98`) cite `a5-failed-runs/falsify/...`
  paths as their basis. Those files are in the ignored directory only; the same records are tracked in
