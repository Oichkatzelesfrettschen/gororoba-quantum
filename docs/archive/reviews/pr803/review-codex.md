In a nine-variable ambient regular ring, rank 3 gives tangent dimension 6, not 4. The substitution silently sends every variable absent from its seven named images to zero (`x_opposite_qi.py:37-70`), so the rank-four parametrization only describes the slice `t3=t8=0`; it cannot be a formal isomorphism onto the six-dimensional germ computed by the script.

The header producer likewise derives a ring from variables that actually occur after presolve (`docs/evidence/a5-kernel-attachments/fiber_inputs.py:132-145`). The intended argument may therefore be repairable, but the retained A5-270 run did not execute that argument.

**Proved defect.** The inference at `x_opposite_qi.py:10-17` and ledger A5-270 (`docs/evidence/a5-exceptional-fibers/ledger.tsv:269`) does not follow from the recorded ambient dimension. A rank-four map into a six-dimensional smooth germ cannot be a formal isomorphism onto that germ.

**Remedy.** Recreate the seven-variable presolved Q(i) ring explicitly, map the twelve generators and the Nakayama generators into it, assert the eliminated set `{t3,t8}`, and rerun the Jacobian, sign-flip, gcd, quotient, and linear-rank checks. The row may return to `proved` only after the retained record names that ring.

**Remedy.** Add a proposition with the fixed pair/degree hypotheses, matrix definitions, specialization map, rank directions, and certificate bindings. Make each successful result name the header and relation digests used by both inequalities.

## Is the characteristic-zero transfer complete after checks 1-3?

**Proved answer: conditionally yes for one fixed pair and one fixed degree, but the PR does not yet state the complete proof.** Checks 1-3 must bind a single integral model, the same presolved variables, the same retained header and K2 relation file, the degree-d monomial-multiple matrix for the upper bound, and the degree-d truncated-rank matrix for the lower bound. The reduction map must be defined at the chosen good prime. The modular certificate must state `r_N=HF(k[y]/K2,d)`.

Under those hypotheses, rank over Q(i) is at least rank after reduction for both matrices. The relation matrix therefore gives the upper bound `h_d(Q(i)) <= HF(k[y]/K2,d)`, while the truncated matrix gives the lower bound `h_d(Q(i)) >= r_N`. Equality of the modular bounds proves the fixed characteristic-zero value. The missing artifact is the explicit matrix/base-change proposition and its digest bindings, not another numerical sample.

The three checks do not establish all degrees, radicality, the W8 component decomposition, formal-germ correctness for A5-270, the exact Plucker limits, or the two-sided real curve-selection statement.

## Degree-seven conjectures and cheapest falsifiers

### VB: a one-ruling final-layer module

**Hypothesis.** The final defect module behaves, degree by degree, like `H^0(P^1,O(2d))`. Its dimension is `2d+1`; parity characters split the monomial basis into `d+1` and `d`, with a degree-dependent character twist swapping which block is larger when d changes parity. This mechanism explains the observed confinement to blocks 0 and 1 and predicts at d=7:

- `r_21=609`, `r_22=624`;
- last jump 15;
- split `7/8/0/0`.

The count-only falsifier is the already preregistered N=21 and N=22 pair (`ledger.tsv:268`). The cheaper mechanism test uses an existing d=4, 5, or 6 final-layer quotient: retain the quotient module, identify two multiplication operators, test the rational-normal-curve relations, and test whether the character twist swaps the parity blocks. A dimension match alone does not identify `P^1`.

### Iso, W8, and X-: a two-ruling final-layer module

**Hypothesis.** The square `(2d+1)^2` is the Hilbert dimension of `H^0(P^1 x P^1,O(2d,2d))`, or equivalently a two-dimensional lattice box built from two independent rulings, against VB's single ruling. The observed character split does not equal the naive parity split, so the mechanism needs a nontrivial character basis or extension. Ledger A5-271 records that a bounded Z2^2-weighted tensor-product search found no model (`ledger.tsv:270`); the Hilbert-count analogy is therefore a falsifiable module hypothesis, not a recovered ring.

The cheapest new count test is X- degree 7 at N=24 and N=25: A5-244 predicts `r_24=771`, `r_25=996`, jump 225, split `49/56/60/60` (`ledger.tsv:243`). The cheaper mechanism test avoids degree 7: extract the final-layer quotient in an existing smaller degree and test for two commuting ruling actions and the predicted bigraded Hilbert series. Failure of commutation or of the bigraded series refutes the proposed explanation even if degree 7 matches the count.
