# Enumeration scripts of the twisted-tower verification

`check.py` and `inv.py` are the exact enumerations behind
[twisted-tower-verification.md](../twisted-tower-verification.md): the associator sign on every basis triple, the
counts N(D), the ANF degree sets, the two-blade zero-product censuses and the two two-sided inverses of e1 + e10.
`check.out` is the output of `check.py`. Both import `gororoba_quantum/cd_core.py`.
